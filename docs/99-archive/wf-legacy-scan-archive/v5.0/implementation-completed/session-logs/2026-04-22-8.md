### G.1 — Expand `legacy-scan-common.sh`

Added 9 UI detection helpers (~180 dòng) tới common.sh v1.0:
- `classify_ui_type <filename>` → page/layout/error/loading/template/default/component

## Deviations từ Design

1. **Line count reduction smaller than target.** Design predicted ~10% net
   reduction (−279 dòng across 5 scripts); actual ~+6% growth. Attributable
   to: (a) atomic_write_json/validate_json wrappers adding ~10 dòng per JSON
   output, (b) per-component clamp helpers requiring `clamp()` utility + inline
   clamp calls, (c) emit loops preserved (not rewritten as shared "emit-ui-entry"
   function). Core Phase G goals — shared library, validation coverage,
   configurable caps, scoring overflow fix — achieved.

2. **Emit loop dedup not done.** Design's "~300 dòng duplicate eliminated"
   target assumed rewriting emit loops với shared `emit_ui_entry` function.
   Đánh giá: risky — ui-coverage-scan.sh và legacy-scan-inventory.sh produce
   slightly different JSON shapes (snapshot vs manifest với `route_group`,
   `parallel_slot`, `intercepts` fields). Extract chỉ small helpers
   (`classify_ui_type`, `is_infra_name`, etc.) và giữ emit loops per-script.
   Follow-up v5.1 if needed.

3. **Domain enrichment in assess.sh (G.3).** Design đề xuất `enrich_domain_hints`
   reading L1 domain-hints.json. Deferred — Phase C chưa wire domain-hints.json
   generation from `detect_domain_hints_en`/`_vn`. Separate task when IPS VN
   keyword pool goes live.

4. **Circular dependency DFS (G.6).** Design đề xuất replace
   `"circular": []` stub với DFS coloring. Giữ stub — no downstream consumer
   of circular info in Phase H/I. Follow-up v5.1.

5. **Cross-platform matrix (G.7).** Only Git Bash Windows tested in dev box.
   WSL/Linux/macOS tests deferred to CI. Portability audit confirms
   `BASH_SOURCE[0]`, portable `stat -c`/`-f` fallbacks, `date -d`/`-j` fallbacks.
