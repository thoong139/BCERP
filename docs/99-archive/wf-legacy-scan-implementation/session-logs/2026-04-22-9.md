## Work breakdown

### H.1 — Resume Router logic (CRITICAL, 3-4h estimated)

**File:** `.claude/skills/workflow/_shared/ips/resume_router.py` (604 dòng)

Implemented:
- `find_latest_active_session()` — wrapper around `scan_state_reader.get_active_session_dir()`.
- `decide_resume_action(state)` — pure routing function, inspect `last_completed`
  + per-layer status/progress/partial, return action payload dict.
- `route_resume(session_id=None)` — full discover → read → decide loop.
- CLI entry `__main__` — emits JSON to stdout, exit code 0/2 distinguish
  natural no-session vs explicit session-not-found.

**16 action types defined** (stable enum for bash switch):
- Fresh layer starts: `start_L1`, `start_L2_rerun_ips_a`, `start_L3`, `start_L4_rerun_ips_b_if_missing`, `start_L5`, `start_L6`
- Mid-layer resume: `resume_L4_batch`, `resume_L4_intra_batch`, `resume_L5_module`, `resume_L5_intra_module`, `resume_L6_regenerate`
- Terminal/special: `session_already_completed`, `no_resumable_session`, `delegate_legacy_subskill`, `fallback_legacy_ledger`, `session_invalid`

**Status-aware routing enhancement:** original routing table keyed only on
`last_completed`. Enhanced router checks layer `status` first — khi
`last_completed=L3` + `L4.status=in_progress` (crash mid-L4 scenario), Router
correctly routes `resume_L4_batch` thay vì `start_L4_rerun_ips_b_if_missing`.
Documented trong module docstring.

**UTF-8 stdout fix:** argparse description + Vietnamese `notes[]` hit
`UnicodeEncodeError` on Windows cp1252 cmd stdout. Fixed bằng
`sys.stdout.reconfigure(encoding="utf-8")` trong `_cli()`.

## Deviations từ Design

1. **Tier 2 E2E BLOCKED (A.3 fixtures).** Same gate as D.9 + E.8 Tier 2.
   Tier 1 delivers equivalent structural coverage (4 levels × 3 scenarios = 12
   cases) via subprocess `kill -9` simulation + Resume Router verification.
   Tier 2 design scripted in smoke test footer for A.3 completion.

2. **Router as Python module, not inline bash.** Original phase-H pseudocode
   suggested bash inline logic. Moved to Python module để (a) share state
   machine awareness với Phase E `scan_state_reader`, (b) unit testable, (c)
   return structured JSON cho bash switch. Bash caller invoke via
   `python -m ips.resume_router`.

3. **Status-aware routing enhancement (beyond phase-H spec).** Original routing
   table keyed only on `last_completed`. Router also inspects layer `status` —
   crucial vì `update_last_completed()` chỉ fire khi layer COMPLETES, không
   khi start. Crash mid-layer leaves `last_completed` ở layer TRƯỚC + layer
   sau `status=in_progress`. Enhanced logic:

   ```
   if L5.status == "in_progress": → _decide_l5_resume()
   elif L4.status == "in_progress": → _decide_l4_resume()
   elif L6.status == "in_progress": → ACTION_RESUME_L6
   else: → fall through to last_completed routing
   ```

   Covered by 3 L1 + 3 L2 + 3 L3 crash scenarios (9/12 H.4 cases exercise
   status-aware path).

4. **UTF-8 stdout reconfigure for Windows cmd.** Vietnamese `notes[]` caused
   `UnicodeEncodeError` trên default Windows cmd (cp1252). Fix: `sys.stdout.
   reconfigure(encoding="utf-8")` trong `_cli()` entry — tránh requiring
   `PYTHONIOENCODING=utf-8` env setup from callers.
