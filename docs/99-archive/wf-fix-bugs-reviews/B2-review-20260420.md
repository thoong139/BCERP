## 5. [Góc độ 4] Safety Defaults ADR-22 — Runtime Enforcement

### 5.1 Rule 1 — Safety Floor (profile ≥ standard phải giữ ≥1 trong {QD1, QD2, QD5})

- **Location:** `isg/isg_recommender.py:610 enforce_safety_floor()`
- **Signature:** `(selected: set[str], profile: str) -> tuple[bool, str | None]`
- **Runtime check:** Intersection `selected & SAFETY_FLOOR_DIMS`; empty → return `(False, err_msg)`.
- **Smoke verify:** `enforce_safety_floor({"QD6","QD7"}, "standard")` → `(False, "LỖI: Profile 'standard' yêu cầu ít nhất 1 trong [QD1, QD2, QD5] phải được chọn...")` ✅
- **Test coverage:** `test_isg_recommender.py` (Part safety floor — 18 class, 115 tests, bao gồm `TestSafetyFloorEnforcement`).

### 5.2 Rule 2 — Verify Ripple (depth=1, strength ≥ 0.5)

- **Scope:** Delegated cho `/wf-fix-execute` Phase 5 (B3), không thuộc B2. Impact Graph được emit bởi `/wf-fix-discover` Layer 0, schema đã sẵn sàng.
- **Status B2:** N/A (pre-B3).

### 5.3 Rule 3 — 3-Tier Token Bucket (12/4/6 non-overridable)

- **Location:** `concurrency/token_bucket.py:154 TokenBucket3Tier.__init__`
- **Runtime check:** `if (global_cap, lane_cap, intra_cap) != DEFAULT_*: raise ValueError("ADR-22 rule 3: không được override default 12/4/6 — nhận X/Y/Z")`.
- **Smoke verify:** `TokenBucket3Tier(global_cap=20)` → `ValueError` ✅
- **Test coverage:** `test_token_bucket.py` (3 class, 12 tests) + `test_integration.py::TestConcurrencyIntegration::test_3tier_override_rejected_at_construction`.

### 5.4 Rule 4 — Secrets CDG (8 hint patterns)

- **Location:** `signal_bus/signal_bus.py:57 SECRETS_HINT_PATTERNS` + `detect_secrets_hint()` (line 288) + triage_status escalation (line 347).

- **Test coverage:** `test_signal_bus.py` (10 class, 42 tests, bao gồm `TestDetectSecretsHint`).

### 5.5 Rule 5 — POST-GATE T1-T4 (SignalBus.flush)

- **Location:** `signal_bus/signal_bus.py` — `flush()` gọi `post_gate_check()` TRƯỚC khi commit atomic write.
- **Tầng kiểm tra:**

### 5.6 Rule 6 — QD3 Never Cached (Defense-in-Depth)

**Cải thiện so với B1** — B1 chỉ enforce schema-level; B2 đã add runtime guard.
