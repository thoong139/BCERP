## 3. [Góc độ 2] B4-2 Scan Cache Prune CLI

### 3.1 File mới `_shared/scan_cache/__main__.py`

Proxy đơn giản — gọi `cache_store.main()`:

```python
from _shared.scan_cache.cache_store import main
sys.exit(main())
```

**Cách gọi:**
```bash
# Prune entries cũ hơn 14 ngày
python -m _shared.scan_cache.cache_store clear --cache-root=.mc-data/cache/wf-fix-bugs/probes/ --older-than=14d

# Set entry (thường gọi từ probe, không cần __main__)
python -m _shared.scan_cache.cache_store set --cache-root=<path> --probe-id=P1-01 --probe-version=1.0.0 --file=<path> --signals-file=<path>
```

**Lý do không tạo thêm CLI wrapper:** `cache_store.py` đã có argparse CLI hoàn chỉnh (set/clear subcommands) từ B2. `__main__.py` chỉ cần proxy để hỗ trợ `python -m` invocation pattern.

## 4. [Góc độ 3] B4-3 Observability Trace Reader

### 4.1 File mới `_shared/read_trace.py` (197 LOC)

**CLI interface:**

```
python -m _shared.read_trace                          # tất cả events
python -m _shared.read_trace --skill=wf-fix-bugs      # lọc theo skill
python -m _shared.read_trace --last=20                # 20 event gần nhất
python -m _shared.read_trace --file=<path>            # đường dẫn khác
python -m _shared.read_trace --summary                # chỉ thống kê
python -m _shared.read_trace --json                   # raw NDJSON output
```

**Tính năng:**
- Đọc NDJSON từ `.mc-data/work/_trace/session-log.json` (CORE-026)
- Filter theo skill (substring, case-insensitive)
- Filter last-N
- Summary stats: tổng event, fail count, breakdown theo skill và event_type
- 6 event type labels tiếng Việt (START/COMPLETE/FAIL/PHASE_START/PHASE_COMPLETE/PHASE_FAIL + CDG)
- Raw JSON export để pipe sang `jq`

### 4.2 Thiết kế

- Không có dependency ngoài stdlib (json, argparse, pathlib, sys)
- Không cần `__init__.py` — chạy trực tiếp `python -m _shared.read_trace`
- Error handling: skip corrupt lines (JSON parse fail), warn to stderr
- Không tạo file, không modify file — read-only observability tool
