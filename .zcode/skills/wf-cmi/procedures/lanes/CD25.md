## §A Header

Lane CD25 đảm bảo **tính liên tục của hành trình người dùng** trong `apps/erp-web`. Detect broken navigation (link tới route không tồn tại → 404), dead-end pages (page không có outgoing nav → user trap), missing breadcrumb (UX deep navigation), inconsistent navigation (menu drift), missing confirmation cho irreversible actions (data loss risk).

**Vì sao quan trọng:**
- Broken user journey → user click button → 404 → mất tin tưởng UI (severity MUST)
- Dead-end page → user phải bấm Back hoặc URL bar (UX trap, đặc biệt mobile)
- Missing breadcrumb → user mất context khi navigate sâu (CRM > Customer > Edit)
- Inconsistent navigation → menu/sidebar drift với actual routes → orphan public routes (security/SEO risk)
- Missing confirmation cho delete/bulk-delete → data loss accident (severity MUST)

### Step CD25.2 — Broken user journey (BROKEN_USER_JOURNEY)

> Link tới route không tồn tại trong fe-route-graph → runtime 404.

**Logic:**
1. Iterate `fe-component-graph.nodes[]` ngoài exclusions
2. Grep patterns trong file_path:
   - `<Link\s+href=\"([^\"]+)\"` (Next.js Link)
   - `router\.push\(['"]([^'"]+)['"]\)` (programmatic)
   - `navigate\(['"]([^'"]+)['"]\)` (react-router)
   - `redirect\(['"]([^'"]+)['"]\)` (Next.js server action)
3. Extract target route path từ capture group
4. Filter external links (`http://`, `https://`, `mailto:`, `tel:`, `#anchor`) — skip
5. Cross-ref `ROUTE_PATHS`:
   - Match exact path → OK
   - Match dynamic [param] (vd `/users/[id]` matches `/users/123`) → OK qua regex normalize
   - Không match → BROKEN_USER_JOURNEY (severity **MUST** — runtime 404 risk)
6. Special: query string `?key=value` strip trước cross-ref

**Signal payload:**
```json
{
  "kind": "BROKEN_USER_JOURNEY",
  "severity": "MUST",
  "category": "VIOLATION",
  "rule_id": "UXFLOW-CD25-001",
  "message": "Component CustomerCard có Link tới /crm/customers/123/contracts nhưng route không tồn tại",
  "affected_entities": ["CustomerCard"],
  "affected_files": ["apps/erp-web/components/customer-card.tsx"],
  "evidence": [{"file": "apps/erp-web/components/customer-card.tsx", "line": 42, "snippet": "<Link href={`/crm/customers/${id}/contracts`}>Hợp đồng</Link>", "target_route": "/crm/customers/[id]/contracts", "resolved": false}],
  "suggested_action": "Tạo route apps/erp-web/app/crm/customers/[id]/contracts/page.tsx HOẶC update link tới route hiện tồn tại"
}
```

### Step CD25.3 — Dead-end page (DEAD_END_PAGE)

> Route tồn tại nhưng không có outgoing navigation → user trap.

**Logic:**
1. Iterate `fe-route-graph.nodes[]` filter `kind=page`
2. Skip routes trong `FLOW_EXCLUSIONS` (vd `/login`, `/reset-password/confirm`, `/logout`)
3. For each route, find associated component file (`page.tsx`)
4. Grep file content tìm outgoing navigation:
   - `<Link\s+href=` (count)
   - `router\.push\(` (count)
   - `navigate\(` (count)
   - `<form action=` (form submit considered nav)
5. Nếu 0 outgoing nav AND không có:
   - `<form>` element (form page có submit)
   - CTA button có handler (action page)
   - → DEAD_END_PAGE (severity SHOULD — UX trap)
6. Cross-validate với `ux_flow_continuity.rules[].id` cho dead-end exemption

**Rule ID:** `UXFLOW-CD25-002`

**Skip patterns:**
- `/(public)/loading.tsx` (Next.js loading page) — không cần outgoing
- `/(error)/error.tsx`, `/global-error.tsx` (error boundaries) — có retry button
- `/(public)/not-found.tsx` (404 page) — link về home đã có

### Step CD25.4 — Missing breadcrumb (MISSING_BREADCRUMB)

> Pages sâu (depth ≥3) không có breadcrumb component.

**Logic:**
1. Iterate `fe-route-graph.nodes[]` filter `kind=page`
2. Strip route groups `(authenticated)`, `(public)` từ route_path
3. Count remaining segments (split by `/`) — depth = count
4. Filter routes có depth ≥ 3 (vd `/crm/customers/[id]/edit` = depth 4)
5. For each route, check:
   - File content qua Grep `<Breadcrumb|<NavBreadcrumb|<Breadcrumbs|breadcrumb:|<BreadCrumb`
   - Parent layout.tsx file content có breadcrumb component
6. Nếu KHÔNG có breadcrumb (component OR parent layout) → MISSING_BREADCRUMB (severity SHOULD)
7. Skip routes trong layouts có `<AutoBreadcrumb />` system

**Rule ID:** `UXFLOW-CD25-003`

### Step CD25.5 — Inconsistent navigation (INCONSISTENT_NAVIGATION)

> Menu/sidebar drift vs actual routes — orphan public routes hoặc menu pointing nowhere.

**Logic:**
1. Scan components trong:
   - `apps/erp-web/components/layout/`
   - `apps/erp-web/components/sidebar/`
   - `apps/erp-web/components/navigation/`
   - `apps/erp-web/components/header/`
2. Extract `<Link href=...>` items + nav data arrays `routes:|menu:|navItems:|nav:`
3. Cross-ref với `ROUTE_PATHS`:
   - Nav item href KHÔNG match route_path → INCONSISTENT_NAVIGATION (severity **MUST** — menu pointing nowhere)
   - Route_path tồn tại nhưng KHÔNG trong bất kỳ nav component → INCONSISTENT_NAVIGATION (severity SHOULD — orphan public route)
4. Skip:
   - Dynamic routes có wildcard (vd `/{module}/list` không count)
   - Routes trong `exclusions.orphan_routes[]` (vd `/healthz`, `/api/internal`, dev-only)

**Rule ID:** `UXFLOW-CD25-004`

### Step CD25.6 — Missing confirmation dialog (MISSING_CONFIRMATION_DIALOG)

> Irreversible actions (delete/bulk-delete/purge/cancel-order) không có confirmation.

**Logic:**
1. Load `CONFIRM_PATTERNS_JSON` — extract patterns matching irreversible actions:
   - `CONF-001` typical: delete entity
   - `CONF-002` typical: bulk-delete
   - `CONF-003` typical: cancel-order / refund / final-action
2. Iterate `fe-component-graph.nodes[]` ngoài exclusions
3. Grep destructive action handler patterns:
   - `onDelete\s*=` / `handleDelete\s*=`
   - `onBulkDelete\s*=` / `handleBulkDelete\s*=`
   - `onPurge\s*=` / `onCancel.*Order` / `onRefund`
   - `onConfirmRemove\s*=`
   - `mutation\.mutate.*[Dd]elete` / `mutation\.mutate.*[Rr]emove`
4. Cross-ref same file/scope tìm confirmation:
   - `<ConfirmationDialog|<AlertDialog|<ConfirmModal|useConfirm\(` (component import + usage)
   - `confirm\(['"]` (native browser confirm — weak nhưng acceptable cho legacy)
   - `<AlertDialog.*onClick.*confirm` (Radix UI pattern)
5. Nếu component có destructive handler nhưng KHÔNG có confirmation → MISSING_CONFIRMATION_DIALOG (severity **MUST** — data loss risk)
6. Cross-validate với `validation_rules.rules[].id="RULE-CD25-001"` (irreversible_action_has_confirmation)

**Rule ID:** `UXFLOW-CD25-005`

**Severity Note:** MUST cho destructive actions = brand-guardian + qa-lead gate (data loss = unrecoverable).

### Step CD25.7 — Write signals.json (Atomic Write)

```bash
SIGNALS_TMP="$LANE_DIR/.signals.tmp.$$"

jq -n \
  --arg sid "$SESSION_ID" \

  '{
    "$schema": "signals-v1",
    "session_id": $sid,
    "generated_at": $ts,
    "lane": $lane,
    "agent_subagent_type": $agent,
    "scope": {"type": $scope_type, "modules": $modules_covered},
    "status": "COMPLETED",
    "scan_duration_sec": ($scan_duration | tonumber),
    "signals": $signals,
    "metadata": {
      "signal_count": ($signals | length),
      "severity_breakdown": {
        "MUST": ([$signals[] | select(.severity == "MUST")] | length),
        "SHOULD": ([$signals[] | select(.severity == "SHOULD")] | length),
        "MAY": ([$signals[] | select(.severity == "MAY")] | length),
        "INFO": ([$signals[] | select(.severity == "INFO")] | length)
      },
      "category_breakdown": {
        "VIOLATION": ([$signals[] | select(.category == "VIOLATION")] | length),
        "GAP": ([$signals[] | select(.category == "GAP")] | length),
        "RECOMMENDATION": ([$signals[] | select(.category == "RECOMMENDATION")] | length)
      },
      "modules_covered": $modules_covered,
      "ci_source": $ci,
      "fallback_used": false,
      "safety_critical_signals": {
        "BROKEN_USER_JOURNEY": ([$signals[] | select(.kind == "BROKEN_USER_JOURNEY")] | length),
        "MISSING_CONFIRMATION_DIALOG": ([$signals[] | select(.kind == "MISSING_CONFIRMATION_DIALOG")] | length)
      }
    }
  }' > "$SIGNALS_TMP"

jq '.' "$SIGNALS_TMP" >/dev/null || die "E044" "signals.json invalid JSON"
mv "$SIGNALS_TMP" "$LANE_DIR/signals.json"
```

## §D POST-GATE (T1→T4 + Auto-Fix)

| Tier | Check | Tool | Fail action |
|------|-------|------|-------------|
| T1 | 3 output files exist | bash | **E044** — Output missing → auto-fix retry x3 |
| T2 | `signals.json` schema = `signals-v1`, `lane` = "CD25", fingerprint unique | jq | **E044** — Schema invalid → re-build |
| T3 | Mọi signal `rule_id` match format `UXFLOW-CD25-\d{3}` (001-005) AND BROKEN_USER_JOURNEY + MISSING_CONFIRMATION_DIALOG luôn severity MUST | jq | **E145** — Rule_id format / severity mismatch → ESCALATE |
| T4 | `affected_files[]` resolve trong `fe-component-graph.json.nodes[].file_path` OR `target_route` resolve trong `fe-route-graph.json.nodes[].route_path` | jq | **E045** — Unresolved → log WARN |

```bash
# T1
for f in signals.json CD25-ux-flow-continuity-report.md lane-status.json; do
  [ -f "$LANE_DIR/$f" ] || die "E044" "Output missing: $f"
done

# T2
SCHEMA=$(jq -r '."$schema"' "$LANE_DIR/signals.json")
LANE_VAL=$(jq -r '.lane' "$LANE_DIR/signals.json")
[ "$SCHEMA" = "signals-v1" ] || die "E044" "Schema mismatch"
[ "$LANE_VAL" = "CD25" ] || die "E044" "Lane field mismatch"

FP_TOTAL=$(jq '.signals | length' "$LANE_DIR/signals.json")
FP_UNIQUE=$(jq '[.signals[].fingerprint] | unique | length' "$LANE_DIR/signals.json")
[ "$FP_TOTAL" = "$FP_UNIQUE" ] || die "E044" "Fingerprint collision"

# T3 — Rule ID format + severity check
INVALID_RULES=$(jq -r '[.signals[] | select(.rule_id | test("^UXFLOW-CD25-[0-9]{3}$") | not) | .rule_id] | length' "$LANE_DIR/signals.json")
[ "$INVALID_RULES" = "0" ] || die "E145" "Invalid rule_id format: $INVALID_RULES"

# Safety-critical severity check
UNSAFE_LOW=$(jq -r '[.signals[] | select((.kind == "BROKEN_USER_JOURNEY" or .kind == "MISSING_CONFIRMATION_DIALOG") and .severity != "MUST")] | length' "$LANE_DIR/signals.json")
[ "$UNSAFE_LOW" = "0" ] || die "E145" "Safety-critical signals (BROKEN_USER_JOURNEY/MISSING_CONFIRMATION_DIALOG) phải severity MUST. Found $UNSAFE_LOW violations."

# T4 — File/route resolution (WARN only)
UNRESOLVED_FILES=$(jq -r --slurpfile g "$FE_COMP_GRAPH" \
  '[.signals[] | .affected_files[]?] | unique
   | map(select(. as $f | ($g[0].nodes | map(.file_path) | index($f)) == null))
   | length' "$LANE_DIR/signals.json")
[ "$UNRESOLVED_FILES" = "0" ] || log_warn "E045" "Unresolved files: $UNRESOLVED_FILES"
```

**Auto-fix budget (CORE-034):** Max 3 retries. Hết → ESCALATE FAIL.
