## §A Header

Lane CD18 đảm bảo **MediatR CQRS pipeline đầy đủ** trong backend .NET — mọi Command/Query có handler + validator, handler có request tương ứng, notification có subscribers, không duplicate handlers. EUREKA-2026 dùng MediatR + FluentValidation, lane này critical cho integrity DDD application layer.

**Vì sao quan trọng:**
- COMMAND_WITHOUT_HANDLER → MediatR throw HandlerNotFoundException runtime (CRITICAL)
- DUPLICATE_HANDLER → MediatR throw AmbiguousHandlerException runtime (CRITICAL)
- COMMAND_WITHOUT_VALIDATOR → input không validate → potential security/data integrity issue (SHOULD)
- HANDLER_WITHOUT_REQUEST → dead code or parser miss (SHOULD)
- NOTIFICATION_WITHOUT_HANDLER → event raise nhưng không ai listen → silent bug (SHOULD)

### Step CD18.2 — Command/Query without handler (COMMAND_WITHOUT_HANDLER)

> Mọi command/query phải có IRequestHandler — runtime guarantee.

**Logic:**
1. Iterate `nodes[]` filter `kind=command OR kind=query`
2. Cross-ref edges[] có `kind=handles` từ handler node tới request node
3. Không tìm thấy edge → COMMAND_WITHOUT_HANDLER (severity MUST)
4. Tham khảo `coverage_indicators.requests_without_handler` (preprocessed count)

**Signal payload:**
```json
{
  "kind": "COMMAND_WITHOUT_HANDLER",
  "severity": "MUST",
  "category": "VIOLATION",
  "rule_id": "CQRS-CD18-001",
  "message": "Command UpdateCustomerCommand không có IRequestHandler — runtime sẽ throw HandlerNotFoundException",
  "affected_entities": ["UpdateCustomerCommand"],
  "affected_files": ["apps/backend/Eureka.Modules.Crm/Customers/Commands/UpdateCustomerCommand.cs"],
  "evidence": [{"file": "apps/backend/Eureka.Modules.Crm/Customers/Commands/UpdateCustomerCommand.cs", "line": 5, "snippet": "public record UpdateCustomerCommand(...) : IRequest<Result>"}],
  "suggested_action": "Create UpdateCustomerCommandHandler : IRequestHandler<UpdateCustomerCommand, Result> trong same folder."
}
```

### Step CD18.3 — Command/Query without validator (COMMAND_WITHOUT_VALIDATOR)

> Public-facing command/query nên có FluentValidation AbstractValidator.

**Logic:**
1. Iterate `nodes[]` filter `kind=command OR kind=query`
2. Cross-ref edges[] có `kind=validates` từ validator node
3. Không tìm thấy AND request có path matching `Application/{Module}/Commands/` hoặc `Queries/` (heuristic public-facing)
4. → COMMAND_WITHOUT_VALIDATOR (severity SHOULD)
5. Skip internal commands trong `Application/Internal/` (nếu có convention)

**Rule ID:** `CQRS-CD18-002`

**Note:** Reference `coverage_indicators.requests_without_validator` cho early estimate. EUREKA fixture có 359 reqs_no_val — cần triage.

### Step CD18.4 — Handler without request (HANDLER_WITHOUT_REQUEST)

> IRequestHandler<X> nhưng X không tồn tại trong codebase.

**Logic:**
1. Iterate `nodes[]` filter `kind=request_handler`
2. Get handled request từ `handles_request` field (parsed generic type X)
3. Lookup X trong nodes (kinds command/query/notification)
4. Không tìm thấy → HANDLER_WITHOUT_REQUEST (severity SHOULD)
5. Tham khảo `coverage_indicators.handlers_without_request` — EUREKA có 1288 hdls_no_req (do v1.0 parser module heuristic)

**Rule ID:** `CQRS-CD18-003`

**Note:** Severity SHOULD vì có thể bug parser (v1.0 Grep-based — namespace resolution không hoàn hảo). Suggested action: verify manual + đợi v2.1 Roslyn AST. KHÔNG hard-block deployment vì có thể false positive.

### Step CD18.5 — Notification without subscribers (NOTIFICATION_WITHOUT_HANDLER)

> INotification raise nhưng không có handler subscribe.

**Logic:**
1. Iterate `nodes[]` filter `kind=notification`
2. Cross-ref edges[] có `kind=handles` từ notification_handler node
3. Không có handler → NOTIFICATION_WITHOUT_HANDLER (severity SHOULD)
4. Cross-validate với `be-domain-graph.json.nodes[]` filter `kind=domain_event_handler` (nếu HAS_BE_DOMAIN=1):
   - Domain event handler có thể subscribe notification từ application layer
   - Confirm với handler edge match

**Rule ID:** `CQRS-CD18-004`

**Skip:** Notifications trong `Application/Notifications/Internal/` (heuristic — internal pub/sub có thể no-op).

### Step CD18.6 — Duplicate handler (DUPLICATE_HANDLER)

> 2+ IRequestHandler cho cùng 1 IRequest<X> → MediatR runtime exception.

**Logic:**
1. Iterate `nodes[]` filter `kind=request_handler`
2. Group by `handles_request` field
3. Filter groups count > 1 → DUPLICATE_HANDLER (severity MUST)
4. Evidence: list tất cả file_path của duplicate handlers

**Rule ID:** `CQRS-CD18-005`

**Edge case:** Generic open type handlers (vd `IRequestHandler<TRequest, TResponse>`) không phải duplicate — chỉ flag handlers cho cùng concrete IRequest type.

### Step CD18.7 — Write signals.json (Atomic Write)

```bash
SIGNALS_TMP="$LANE_DIR/.signals.tmp.$$"

jq -n \
  --arg sid "$SESSION_ID" \
  --arg ts "$(date -Iseconds)" \
  --arg lane "CD18" \
  --arg agent "architect" \
  --arg scope_type "$SCOPE_TYPE" \
  --argjson signals "$ALL_SIGNALS_JSON" \
  --argjson modules_covered "$MODULES_COVERED" \
  --arg ci "$CI_SOURCE" \
  '{
    "$schema": "signals-v1",
    "session_id": $sid,
    "generated_at": $ts,
    "lane": $lane,
    "agent_subagent_type": $agent,
    "scope": {"type": $scope_type, "modules": $modules_covered},
    "status": "COMPLETED",
    "scan_duration_sec": ($scan_duration | tonumber),
    "signals": $signals,
    "metadata": {
      "signal_count": ($signals | length),
      "severity_breakdown": {
        "MUST": ([$signals[] | select(.severity == "MUST")] | length),
        "SHOULD": ([$signals[] | select(.severity == "SHOULD")] | length),
        "MAY": ([$signals[] | select(.severity == "MAY")] | length),
        "INFO": ([$signals[] | select(.severity == "INFO")] | length)
      },
      "category_breakdown": {
        "MISSING_INVARIANT": ([$signals[] | select(.category == "MISSING_INVARIANT")] | length),
        "VIOLATION": ([$signals[] | select(.category == "VIOLATION")] | length),
        "GAP": ([$signals[] | select(.category == "GAP")] | length),
        "RECOMMENDATION": ([$signals[] | select(.category == "RECOMMENDATION")] | length)
      },
      "modules_covered": $modules_covered,
      "ci_source": $ci,
      "fallback_used": false
    }
  }' > "$SIGNALS_TMP"

jq '.' "$SIGNALS_TMP" >/dev/null || die "E044" "signals.json invalid JSON"
mv "$SIGNALS_TMP" "$LANE_DIR/signals.json"
```

## §D POST-GATE (T1→T4 + Auto-Fix)

| Tier | Check | Tool | Fail action |
|------|-------|------|-------------|
| T1 | 3 output files exist | bash | **E044** — Output missing → auto-fix retry x3 |
| T2 | `signals.json` schema = `signals-v1`, `lane` = "CD18", fingerprint unique | jq | **E044** — Schema invalid → re-build |
| T3 | Mọi signal `rule_id` match format `CQRS-CD18-\d{3}` (001-005) | jq | **E045** — Format invalid → re-render |
| T4 | `affected_entities[]` resolve trong `be-cqrs-graph.nodes[].name` (MUST signals) hoặc be-domain (cross-layer event) | jq | **E045** — Entity unresolved → log WARN |

```bash
# T1
for f in signals.json CD18-cqrs-pipeline-integrity-report.md lane-status.json; do
  [ -f "$LANE_DIR/$f" ] || die "E044" "Output missing: $f"
done

# T2
SCHEMA=$(jq -r '."$schema"' "$LANE_DIR/signals.json")
LANE_VAL=$(jq -r '.lane' "$LANE_DIR/signals.json")
[ "$SCHEMA" = "signals-v1" ] || die "E044" "Schema mismatch"
[ "$LANE_VAL" = "CD18" ] || die "E044" "Lane field mismatch"

FP_TOTAL=$(jq '.signals | length' "$LANE_DIR/signals.json")
FP_UNIQUE=$(jq '[.signals[].fingerprint] | unique | length' "$LANE_DIR/signals.json")
[ "$FP_TOTAL" = "$FP_UNIQUE" ] || die "E044" "Fingerprint collision"

# T3
INVALID_RULES=$(jq -r '[.signals[] | select(.rule_id | test("^CQRS-CD18-[0-9]{3}$") | not) | .rule_id] | length' "$LANE_DIR/signals.json")
[ "$INVALID_RULES" = "0" ] || die "E045" "Invalid rule_id format: $INVALID_RULES"

# T4 — Entity resolution (WARN only)
if [ "$HAS_BE_DOMAIN" = "1" ]; then
  UNRESOLVED=$(jq -r --slurpfile cqrs "$BE_CQRS" --slurpfile dom "$BE_DOMAIN" \
    '[.signals[] | .affected_entities[]?] | unique
     | map(select(. as $e |
         ($cqrs[0].nodes | map(.name) | index($e)) == null
         and ($dom[0].nodes | map(.name) | index($e)) == null))
     | length' "$LANE_DIR/signals.json")
else
  UNRESOLVED=$(jq -r --slurpfile cqrs "$BE_CQRS" \
    '[.signals[] | .affected_entities[]?] | unique
     | map(select(. as $e | ($cqrs[0].nodes | map(.name) | index($e)) == null))
     | length' "$LANE_DIR/signals.json")
fi
[ "$UNRESOLVED" = "0" ] || log_warn "E045" "Unresolved entities count: $UNRESOLVED"
```
