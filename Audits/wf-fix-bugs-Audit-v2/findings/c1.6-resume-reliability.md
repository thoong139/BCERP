## C1.6.1 — Resume đúng session (latest in_progress matching scope)

**Verdict:** PASS

**Evidence:**

1. `procedures/session-dir.md` §5 (line 172-182): Resume flow resolves `$SESSION_DIR` bằng cách:
   - Trường hợp A: `--session=<id>` tường minh → verify directory tồn tại
   - Trường hợp B: auto-pick latest `in_progress` matching scope+slug qua:
     ```bash
     SESSION_ID=$(tac "$INDEX" \
       | jq -r --arg s "${SCOPE:-all}" --arg sl "$SLUG" \
           'select(.status == "in_progress" and .scope == $s and .slug == $sl) | .session_id' \
       | head -1)
     ```
   - `tac` (reverse cat) đọc từ dưới lên → pick latest
   - Filter: `status == "in_progress"` + scope match + slug match

2. `procedures/resume-routing.md` §1 (line 16-20): Routing table phân biệt 3 trạng thái:
   - `in_progress` → tiếp tục từ `next_action`
   - `paused` → re-render menu/prompt
   - `completed` → hiển thị done + cross-skill suggest

3. `SKILL.md` Step 6 (line 422-425): `--resume` + scope khác session gốc → WARN + AskUserQuestion (guard bổ sung)

4. `SKILL.md` Step 1 (line 197-198): `--resume` → lazy-load `procedures/resume-routing.md`, KHÔNG vào new session flow

**Analysis:** Logic scope-filter đúng: latest `in_progress` trong _index/sessions.jsonl, lọc theo scope+slug. Không pick nhầm `completed`. Guard scope mismatch ở Step 6.
