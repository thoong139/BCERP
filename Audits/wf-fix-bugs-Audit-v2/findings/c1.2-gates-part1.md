**Findings:**

1. **Escape hatch hoạt động đúng:** `MCV3_FIX_BUGS_LEGACY_DEPRECATED_OK=1` → WARN stderr + exit 0. Script kiểm tra escape hatch TRƯỚC khi detect legacy paths (`set -euo pipefail` gated correctly). ✅

4. **Exit code mismatch (WARN):** Contract `_contract.json` quy định `E_LEGACY_BLOCK.exit_code: 78`, nhưng script abort (option 3) thực tế `exit 2`. Phân tích:

## C1.2.2 — CI PRE-GATE Freshness Check (PASS)

**Files:**
- `.claude/scripts/ci-freshness-check.sh` (90 dòng)
- `.claude/scripts/ci-detect.sh` (380 dòng)
- `.claude/skills/workflow/wf-fix-bugs/procedures/ci-pre-gate.md` (123 dòng)
- `.claude/skills/workflow/wf-fix-bugs/SKILL.md` §Step 3 (dòng 212-223)

**Findings:**

1. **4-level freshness model:** `ci-freshness-check.sh` tuân thủ Protocol 20 §20.7:
   - Exit 0: `ok` — index up-to-date
   - Exit 1: `light` — ≤5 commits behind
   - Exit 2: `strong` — 6-20 commits behind
   - Exit 3: `severe` — >20 commits behind

2. **Không block workflow:** SKILL.md Step 3 gọi `bash .claude/scripts/ci-freshness-check.sh` KHÔNG có `|| exit $?` → exit codes từ freshness check KHÔNG propagated lên orchestrator. ci-pre-gate.md procedure chỉ parse `FRESHNESS_LEVEL` và `FRESHNESS_BEHIND` từ output JSON, không dùng exit code để quyết định continue/stop. ✅

3. **Severe stale (exit 3, >20 behind):** Hiển thị URGENT warning message (`"Index is $BEHIND commits behind HEAD. Impact analysis likely incomplete."`) nhưng KHÔNG block. Đúng với yêu cầu checklist "Hiển thị cảnh báo nhưng không block workflow". ✅

4. **Index age check (7+ days):** Emit WARNING stderr nếu index > 7 ngày trong ci-detect.sh và ci-freshness-check.sh. Non-blocking. ✅

5. **Corner case handling:**
   - Non-git repo → `{"status":"skipped","reason":"not a git repository"}` exit 0 ✅
   - No cache file → `{"status":"skipped","reason":"no cache file"}` exit 0 ✅
   - GitNexus not available → `{"status":"skipped","reason":"gitnexus not available"}` exit 0 ✅
   - Index commit not in history → `{"status":"unknown","reason":"index_commit not in history"}` exit 0 ✅
   - index_commit == HEAD → exit 0 with `level:ok` in JSON ✅

**Verdict:** PASS — freshness check warns at all 4 levels but never blocks, all corner cases handled gracefully.

## C1.2.3 — CI PRE-GATE Graceful Absence (PASS)

**Files:**
- `.claude/scripts/ci-detect.sh` (380 dòng) — full implementation
- `.claude/skills/workflow/wf-fix-bugs/procedures/ci-pre-gate.md` §Graceful Degradation (dòng 116-123)
- `.claude/skills/workflow/wf-fix-bugs/SKILL.md` §Step 3 (dòng 212-223)

**Findings:**

1. **No CI tools available path:** `ci-detect.sh` khi không phải git repo → `{"status":"no_git","message":"Not a git repository"}` exit 1. ci-pre-gate.md: exit 1 → "skip ALL CI detection". ✅

2. **Lock held fallback:** Khi lock được giữ bởi session khác:
   - `ci-detect.sh` → exit 2, `{"status":"lock_held","action":"fallback_grep"}`
   - ci-pre-gate.md: "Lock held by peer → fallback Grep/Glob, skip Steps 0.N2-0.N5"
   - KHÔNG block, KHÔNG crash. ✅

3. **MCP tools unavailable:** ci-pre-gate.md §Step 0.N2.D: "Ghi nhận `available: false` cho tool tương ứng (KHÔNG block PRE-GATE)." Cache TTL cho absent tools: GitNexus 4h, Serena 1h (ngắn hơn để retry sớm). ✅

4. **Cache schema migration (v1→v2):** `ci-detect.sh` tự động detect và migrate cache schema cũ → không crash trên cache version cũ. Corrupt cache → tự động rm + re-scan. ✅

5. **Stale lock takeover:** Khi lock held > 60s (STALE_TIMEOUT_SEC) → `break_stale_lock()` → re-acquire. ✅

6. **Lock atomicity:** Dùng noclobber (`set -C`) để acquire lock → POSIX-compliant cross-process atomic. ✅

7. **ci-pre-gate.md explicit degradation:** "ci-detect.sh fail → WARNING → continue without CI (Grep/Glob fallback)". "Non-git project → skip all CI steps (exit 1 from ci-detect.sh)". "CI context empty → sub-skills use standard Grep/Glob (current behavior preserved)". ✅

**Verdict:** PASS — tất cả degradation paths handled: no CI tools → skip, lock held → fallback Grep/Glob, MCP absent → cache TTL retry, JSON corrupt → auto recovery, stale lock → takeover.
