# Test Fixtures Catalog

> **Mục đích:** Cung cấp known-bug projects để đo precision/recall của 43 probes (7 dim).
> **Build order:** Theo thứ tự audit dim (xem [11-stages-and-gates.md §Stage 1](../11-stages-and-gates.md)).
> **Pytest harness:** Tự động hoá regression test (DEC-004).

## Convention

Mỗi fixture `qd<N>-test/`:
- `README.md` — Liệt kê expected signals per probe + run instructions
- `expected-signals.json` — Schema `lane-signals-v1`, machine-readable
- `accuracy-report.md` — Confusion matrix + Precision/Recall/F1 (sinh sau `run.sh`)
- `run.sh` — Local runner: setup → invoke probe → compare with expected
- `positive/` — Code có known bugs (≥5 cases)
- `negative/` — Code legit, không nên flag (≥5 cases)
- `advanced/` — Edge cases (optional, bắt buộc cho QD3)

## Fixture cases per dim (high-level)

### QD1 Functional (đã pre-seeded ở [02-qd1](../02-qd1-functional-audit.md))
- **Positive:** REQ-ID orphan, 404 link, broken form, orphan button, missing nav
- **Negative:** Legit dynamic route, intentional empty POST validation, async download
- **Multi-stack:** Node Express + .NET WebAPI + Python FastAPI + i18n VI app

### QD3 Security (high priority, 5 advanced cases)
- **Positive:** Hardcoded API key, SQL injection (string concat), XSS dangerouslySetInnerHTML, wildcard CORS với credentials, missing CSP
- **Negative:** UUID v4, parameterized SQL, innerHTML constant, scoped CORS, strict CSP
- **Advanced:** JWT alg=none, SSRF redirect, mass assignment, IDOR no-auth, session fixation

### QD6 Data Integrity
- **Positive:** Migration không có down(), ORM-DB length mismatch, FK thiếu cascade, type Date vs TIMESTAMP, seed violate unique
- **Negative:** Intentional one-way migration, computed property, soft-delete pattern, dev seed

### QD2 Business
- **Positive:** Tính % quên `/100`, hardcoded VAT 10%, skip approval, audit trail thiếu actor, currency rate cũ
- **Negative:** HTTP status magic 200, UI indexing constant, legit calculation, correct approval flow

### QD4 Performance
- **Positive:** Bundle >1MB (lodash full), API sleep 5s, N+1 query loop, no removeEventListener, LCP >4s
- **Negative:** Bundle 800KB rich editor, API 1.5s aggregation, JOIN single query, WeakMap cleanup, LCP 1.5s

### QD5 UX/A11y
- **Positive:** Image no alt, button contrast 3.5:1, form no label, modal no focus trap, tab order sai
- **Negative:** Decorative role=presentation, large heading 18pt 3:1 OK, label nhúng input, modal focus trap đúng, visual tab order

### QD7 Compat
- **Positive:** Array.at() không polyfill, API v2 missing fallback v1, document.write deprecated, viewport 320px vỡ, missing autoprefixer
- **Negative:** Modern feature có detection, API v2 deprecation header, console.log not deprecated, responsive 320-1920px

## Run

```bash
# Single dim
cd plans/wf-fix-bugs-dimensions-audit-v1/fixtures/qd<N>-test
./run.sh

# All dims via pytest (Stage 4 re-audit)
cd plans/wf-fix-bugs-dimensions-audit-v1/tests
./run-audit-tests.sh

# Compare with baseline (after Stage 3 implementation)
./run-audit-tests.sh --compare-baseline
```

## Tích hợp evals/ (Stage 2, DEC-006)

Sau khi G2 pass, fixtures được sync vào `wf-fix-{dim}/evals/evals.json` qua:

```bash
scripts/sync-audit-to-evals.sh --dim=QD<N>
```

Script này:
1. Đọc `expected-signals.json` của fixture
2. Convert sang format `EVAL-SCHEMA.md`
3. Append vào `wf-fix-{dim}/evals/evals.json` với `source: audit-v1`

## DoD per fixture

Xem [13-definition-of-done.md §Phase 3](../13-definition-of-done.md). Tóm tắt:
- [ ] ≥5 positive + ≥5 negative cases
- [ ] `run.sh` exit 0
- [ ] Pytest pass
- [ ] Precision ≥0.7, Recall ≥0.6 (nếu thấp → ghi finding)
- [ ] `accuracy-report.md` có confusion matrix
