## 📐 SESSION PROTOCOL — Quy tắc operational

### Đầu phiên
1. Đọc context theo §INSTRUCTIONS Phase 1 (chỉ 3 file)
2. Confirm Current Task với user trước khi execute
3. Plan execution với TodoWrite nếu task có ≥3 sub-steps

### Trong phiên
- **Time-box:** Mỗi phiên KHÔNG quá 2-3 atomic tasks (tránh context overflow)
- **Lazy load:** Chỉ Read file cần cho task hiện tại
- **Verify gate:** Sau mỗi task, run DoD verify trước khi mark done
- **Tuân BHV:**
  - BHV-001: Hỏi nếu ambiguous (vd: "schema mismatch — fix theo cách A hay B?")
  - BHV-002: Đơn giản, không add scope ngoài Current Task
  - BHV-003: Surgical changes
  - BHV-004: Verify checkpoint sau mỗi step

### Cuối phiên (BẮT BUỘC, không skip)
1. Mark `[x]` cho tasks hoàn thành trong §TASK QUEUE
2. Update §CURRENT STATE (Last session, Stage, Gate, Current Task)
3. Set §NEXT ACTION với steps cụ thể (file paths, commands, expected output)
4. Append §ACTIVITY LOG
5. Update §BLOCKERS nếu có
6. Update `progress.md` (canonical tracker) nếu có Stage/Phase complete

### Edge cases
| Tình huống | Xử lý |
|---|---|
| Task quá lớn, không xong 1 phiên | Split thành sub-tasks trong §TASK QUEUE, mark partial progress |
| Phát hiện scope thay đổi | DỪNG. Đề xuất user trước khi continue. Update §BLOCKERS nếu cần. |
| Gate verify fail | KHÔNG chuyển stage. Fix gate criteria trước. |
| User muốn skip stage | Cảnh báo CORE-024 (downstream cần upstream evidence) + ASK confirm |
| Tìm thấy file outdated/stale | Báo user, đề xuất action (delete/merge/archive). KHÔNG tự xóa. |

## ⚠️ MISTAKE PREVENTION

Lessons learned từ phiên thiết kế plan v1.1:

1. **KHÔNG tự xóa files** → Always ASK user (deletion là destructive action)
2. **KHÔNG skip Phase order** — Phase 4 phải xong trước Phase 5 revise
3. **KHÔNG promote tentative → verified** mà không có file:line evidence
4. **Update progress.md sau MỖI phase complete** (không batch ở cuối stage)
5. **Verify count khớp giữa progress.md ↔ roadmap.md ↔ cross-cutting** (số IMPs verified, tentative phải sync)
6. **KHÔNG mark Section complete khi nội dung là TODO/placeholder**
7. **YAML frontmatter must be valid** — test với `yq` trước commit
8. **Reference paths must be valid** — không link tới file đã rename/xóa
