## Regulatory Framework by Industry

### 1. Financial Services

| Regulation | Scope | Key Requirements |
|------------|-------|------------------|
| Basel II/III | Banking | Capital adequacy, risk management |
| AML/CTF | All financial | Anti-money laundering, KYC |
| MiFID II | Investment | Transaction reporting, best execution |
| PCI-DSS | Card payments | Card data security |

### 2. Healthcare

| Regulation | Scope | Key Requirements |
|------------|-------|------------------|
| HIPAA (US) | Healthcare | Patient data privacy |
| Decree 117/2020 (VN) | Healthcare | Medical examination regulations |
| GDPR | EU patients | Personal data protection |

### 3. Data Protection

| Regulation | Scope | Key Requirements |
|------------|-------|------------------|
| GDPR | EU citizens | Consent, right to erasure, DPO |
| Decree 13/2023 (VN) | Vietnam | Personal data protection |
| CCPA | California consumers | Data rights, opt-out |

### 4. Corporate Governance

| Regulation | Scope | Key Requirements |
|------------|-------|------------------|
| SOX | US public companies | Internal controls, audit trail |
| ISO 19600 | General | Compliance management system |
| ISO 37001 | General | Anti-bribery management |

## Regulatory Change Management

```
┌─────────────────────────────────────────────────────────────┐
│              REGULATORY CHANGE PROCESS                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [Monitor]    [Assess]    [Plan]    [Implement]    [Verify] │
│      │           │          │           │            │      │
│      ▼           ▼          ▼           ▼            ▼      │
│   Identify    Impact      Gap        Update       Test      │
│   changes    analysis   analysis   systems      controls   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Change Categories:**
1. **Critical**: Immediate action required (within 30 days)
2. **High**: Action required within 90 days
3. **Medium**: Action required within 180 days
4. **Low**: Next regular update cycle

## Common Compliance Requirements

### Data Retention

| Document Type | Retention Period | Regulation |
|---------------|------------------|------------|
| Financial records | 10 years | Tax law |
| Employment records | 5 years after termination | Labor law |
| Contracts | 10 years after expiry | Civil code |
| Customer data | Duration of relationship + 5 years | Data protection |
| Audit logs | 7 years | SOX/ISO |

### Access Control

| Principle | Requirement |
|-----------|-------------|
| Least privilege | Access only what's needed for role |
| Segregation of duties | No single person controls full process |
| Need to know | Access based on job requirements |
| Regular review | Quarterly access certification |

### Reporting Obligations

| Report | Frequency | Recipient |
|--------|-----------|-----------|
| Financial statements | Quarterly/Annual | Regulators, Board |
| Tax filings | Monthly/Annual | Tax authority |
| Incident reports | As occurred | Regulators (if material) |
| Compliance status | Quarterly | Board/Audit Committee |

## Compliance Technology Requirements

### System Capabilities

| Capability | Purpose |
|------------|---------|
| Audit trail | Track all changes, who, when, why |
| Access control | Role-based permissions |
| Document management | Policy storage, version control |
| Workflow | Approval processes, segregation |
| Reporting | Compliance dashboards, metrics |
| Alerting | Threshold breaches, exceptions |

### Data Requirements

| Data Element | Purpose |
|--------------|---------|
| User ID | Who performed action |
| Timestamp | When action occurred |
| Action type | What was done |
| Before/after values | What changed |
| Reason code | Why change made |
| Approval chain | Who authorized |
