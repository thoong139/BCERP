## 1. Customer Journey Stages

```
┌───────────┐   ┌─────────────┐   ┌────────────┐   ┌───────────┐   ┌──────────┐
│ Awareness │──▶│ Consideration│──▶│ Conversion │──▶│ Retention │──▶│ Advocacy │
└───────────┘   └─────────────┘   └────────────┘   └───────────┘   └──────────┘
      │               │                  │               │              │
      ▼               ▼                  ▼               ▼              ▼
   Brand         Educational         Persuasion       Engagement    Referral
   Visibility    Content             Offers           Programs     Programs
   PR            Case Studies        Demos            Newsletters  Reviews
   Ads           Webinars            Trials           Support      UGC
```

### Stage Metrics

| Stage | Primary KPI | Secondary KPIs | Channels |
|-------|-------------|----------------|----------|
| **Awareness** | Reach, Impressions | Brand search volume, Social followers | Display, Social, PR |
| **Consideration** | Website visits, Content downloads | Time on site, Pages/session | SEO, Content, Email |
| **Conversion** | Leads, Sign-ups | CPL, Conversion rate | Ads, Landing pages |
| **Retention** | Repeat purchases, NPS | Churn rate, LTV | Email, Community |
| **Advocacy** | Referrals, Reviews | NPS, UGC volume | Referral, Social |

## 2. Core Marketing Processes

### Process 1: Campaign Planning & Execution

```
Strategy → Planning → Creation → Launch → Optimize → Report
    │         │           │         │          │         │
    ▼         ▼           ▼         ▼          ▼         ▼
 Goals     Budget     Content    Go Live    A/B Test   Analysis
 KPIs      Channels   Creative   Tracking   Adjust     Insights
 Timeline  Audience   Approval   Setup      Scale      Learnings
```

| Phase | Owner | Key Activities | Deliverables |
|-------|-------|----------------|--------------|
| Strategy | Marketing Manager | Set goals, Define audience | Campaign brief |
| Planning | Campaign Specialist | Budget allocation, Channel mix | Campaign plan |
| Creation | Content + Creative | Develop assets | Creative assets |
| Launch | Campaign Specialist | Configure, Test, Deploy | Live campaign |
| Optimize | Campaign Specialist | Monitor, Test, Adjust | Optimization log |
| Report | Marketing Analyst | Analyze, Document | Campaign report |

### Process 2: Lead Generation & Nurturing

```
Traffic → Capture → Score → Segment → Nurture → Qualify → Handoff
    │        │        │         │         │         │        │
    ▼        ▼        ▼         ▼         ▼         ▼        ▼
 Ads      Forms    Points    Cohorts   Emails    MQL/SQL   Sales
 SEO      Landing  Rules     Industry  Sequences Threshold Reps
 Social   Gated    Behavior  Persona   Content   Sales     CRM
 Content  Content
```

| Step | System Actions | Success Criteria |
|------|----------------|------------------|
| Traffic | Channel attribution | Cost per visitor |
| Capture | Form submission, Cookie tracking | Conversion rate |
| Score | Auto-score based on rules | Score accuracy |
| Segment | Apply tags, Add to lists | Segment engagement |
| Nurture | Trigger email sequences | Open rate, Click rate |
| Qualify | Score threshold check | MQL → SQL rate |
| Handoff | Create opportunity, Assign rep | Handoff SLA |

### Process 3: Content Production

```
Ideation → Brief → Create → Review → Approve → Publish → Distribute
    │        │        │        │        │         │         │
    ▼        ▼        ▼        ▼        ▼         ▼         ▼
 Research  Topic    Writer   Editor   Manager   CMS       Social
 Trends   Outline   Design   SEO      Legal     SEO       Email
 Gap      Assets    Video    Brand    Compliance Publish   Paid
```

| Phase | Owner | Activities | Tools |
|-------|-------|------------|-------|
| Ideation | Content Manager | Keyword research, Competitor analysis | SEO tools, Analytics |
| Brief | Content Manager | Define scope, Requirements | Project management |
| Create | Writer/Designer | Write, Design, Produce | Content tools |
| Review | Editor | Edit, SEO check, Brand check | Checklist |
| Approve | Marketing Manager | Final review, Legal (if needed) | Workflow |
| Publish | Content Manager | Upload, Optimize, Schedule | CMS |
| Distribute | Campaign Specialist | Share, Promote, Amplify | Social, Email, Ads |

### Process 4: Marketing-to-Sales Handoff

```
Lead Score → MQL Check → Sales Accept → SQL → Opportunity → Closed
     │           │            │           │         │          │
     ▼           ▼            ▼           ▼         ▼          ▼
  ≥75 pts    Marketing    Sales Rep   BANT     CRM        Revenue
  Demo req   Review       Accepts     Qualify  Tracking   Attribution
```

| Step | Criteria | Owner | SLA |
|------|----------|-------|-----|
| Lead Score | Score ≥75 or Demo request | System | Immediate |
| MQL Check | Valid contact, Right persona | Marketing Ops | <1 hour |
| Sales Accept | Rep accepts lead | Sales Rep | <4 hours |
| SQL | BANT qualified | Sales Rep | <24 hours |
| Opportunity | Deal potential confirmed | Sales Rep | <48 hours |

## 6. KPIs & Metrics

### Funnel Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| Impressions | Count of ad impressions | Per plan |
| Click-through Rate (CTR) | Clicks / Impressions × 100 | >2% (display), >0.5% (social) |
| Conversion Rate | Conversions / Clicks × 100 | >5% (landing page) |
| Cost per Lead (CPL) | Spend / # Leads | Per channel |
| Lead-to-MQL Rate | MQLs / Total Leads × 100 | >20% |
| MQL-to-SQL Rate | SQLs / MQLs × 100 | >30% |

### Campaign Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| Cost per Acquisition (CPA) | Spend / # Conversions | Per channel |
| Return on Ad Spend (ROAS) | Revenue / Spend | >300% |
| Campaign ROI | (Revenue - Cost) / Cost × 100 | >200% |
| Customer Acquisition Cost (CAC) | Total Marketing Cost / # Customers | Per segment |

### Content Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| Page Views | Count | Per content |
| Avg Time on Page | Total time / Page views | >2 minutes |
| Bounce Rate | Single page sessions / Total | <60% |
| Content Conversion Rate | Conversions / Page views | >2% |
| Social Shares | Count | Per content |

### Email Metrics

| Metric | Formula | Target |
|--------|---------|--------|
| Open Rate | Opens / Delivered × 100 | >20% |
| Click Rate | Clicks / Delivered × 100 | >3% |
| Unsubscribe Rate | Unsubscribes / Delivered × 100 | <0.5% |
| Reply Rate | Replies / Delivered × 100 | Varies |

### Attribution Models

| Model | When to Use | Description |
|-------|-------------|-------------|
| First Touch | Brand awareness focus | 100% credit to first interaction |
| Last Touch | Direct response focus | 100% credit to last interaction |
| Linear | Multi-touch equals | Equal credit across all touches |
| Time Decay | Long sales cycles | More credit to recent touches |
| Position-based | Balanced approach | 40% first, 40% last, 20% middle |
