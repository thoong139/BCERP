# Marketing Domain - User Personas

> **Domain**: Marketing / Quản trị Marketing
> **Last Updated**: 2026-03-07

## Persona 1: Marketing Manager

### Profile
| Thuộc tính | Giá trị |
|------------|---------|
| **Role** | Marketing Manager |
| **Experience** | 5-8 năm |
| **Report to** | Marketing Director / CMO |
| **Focus** | Campaign strategy, Team management |

### Daily Tasks
1. Review campaign performance metrics
2. Coordinate với Sales on lead handoff
3. Approve content và creative
4. Manage marketing budget
5. Plan upcoming campaigns

### Key Decisions
| Decision | Authority Level | Data Needed |
|----------|-----------------|-------------|
| Approve campaign (≤budget) | Execute | Campaign plan, Expected ROI |
| Allocate budget | Recommend | Performance data, Goals |
| Pause underperforming ads | Execute | Performance metrics |
| Approve content | Execute | Brand guidelines, Compliance |

### Pain Points
- Fragmented data across channels
- Difficult to attribute revenue
- Manual reporting
- Slow content approval

### Must-have Features
- ✅ Unified dashboard
- ✅ Attribution reporting
- ✅ Automated reports
- ✅ Content workflow

## Persona 2: Campaign Specialist

### Profile
| Thuộc tính | Giá trị |
|------------|---------|
| **Role** | Campaign Specialist / Digital Marketer |
| **Experience** | 2-5 năm |
| **Report to** | Marketing Manager |
| **Focus** | Campaign execution, Optimization |

### Daily Tasks
1. Create và launch campaigns
2. Monitor ad performance
3. Optimize targeting và bidding
4. A/B test creatives
5. Update campaign budgets

### Key Decisions
| Decision | Authority Level | Data Needed |
|----------|-----------------|-------------|
| Adjust daily budget (≤20%) | Execute | Performance data |
| Pause ad set | Execute | CPA, CTR thresholds |
| Change targeting | Execute | Audience insights |
| Request budget increase | Request | Performance justification |

### Pain Points
- Multiple platforms to manage
- Manual bid adjustments
- No cross-channel view
- Late performance data

### Must-have Features
- ✅ Multi-platform integration
- ✅ Automated bidding rules
- ✅ Cross-channel dashboard
- ✅ Real-time data
