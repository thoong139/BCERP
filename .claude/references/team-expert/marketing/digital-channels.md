## 1. Search Engine Optimization (SEO)

### Technical SEO Requirements

| Component | Yêu cầu hệ thống | Mức độ |
|-----------|-------------------|--------|
| Crawlability | Robots.txt management, XML sitemap generation, crawl budget optimization | Bắt buộc |
| Indexation | Index coverage monitoring, canonical URL management, noindex controls | Bắt buộc |
| Core Web Vitals | LCP < 2.5s, INP < 200ms, CLS < 0.1 — monitoring + alerting | Bắt buộc |
| Structured Data | Schema markup (Article, Product, FAQ, HowTo, Organization), validation | Nên có |
| Mobile Optimization | Responsive design, viewport config, touch target spacing | Bắt buộc |
| URL Structure | Clean hierarchy, breadcrumb navigation, redirect chain management | Bắt buộc |
| International SEO | Hreflang tags, geo-targeting, multi-language support | Tùy dự án |

### On-Page SEO Checklist

| Element | Quy tắc | System Support |
|---------|---------|----------------|
| Title tag | Primary keyword + modifier + brand (50-60 ký tự) | Template engine |
| Meta description | Keyword + CTA (150-160 ký tự) | Template engine |
| H1 tag | Duy nhất, chứa primary keyword | Validation rule |
| Heading hierarchy | H1 → H2 → H3 logic | Content editor |
| Internal linking | Contextual links đến related content | Link suggestion |
| Image alt text | Mô tả nội dung, chứa keyword tự nhiên | Content editor |
| Canonical URL | Self-referencing, tránh duplicate | Auto-generate |

### Keyword Strategy Framework

| Loại keyword | Đặc điểm | Ví dụ | Ứng dụng |
|-------------|----------|-------|----------|
| Head terms | Volume cao, cạnh tranh cao | "CRM software" | Pillar pages |
| Long-tail | Volume thấp, intent rõ | "best CRM for small business 2026" | Blog, guides |
| Transactional | Intent mua hàng | "buy CRM subscription" | Landing pages |
| Informational | Intent tìm hiểu | "how to manage customer relationships" | Blog, guides |
| Branded | Chứa tên thương hiệu | "Salesforce vs HubSpot" | Comparison pages |

### Topic Cluster Architecture

```
                    ┌─────────────┐
                    │ Pillar Page  │
                    │ (Head term)  │
                    └──────┬──────┘
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
  │ Cluster Post │ │ Cluster Post │ │ Cluster Post │
  │ (Long-tail)  │ │ (Long-tail)  │ │ (Long-tail)  │
  └──────────────┘ └──────────────┘ └──────────────┘

  Tất cả cluster posts link về pillar page.
  Pillar page link ra cluster posts.
```

## 2. Social Media Marketing

### Platform Comparison Matrix

| Platform | Audience | Content Format | Best For | Key Metrics |
|----------|----------|---------------|----------|-------------|
| **LinkedIn** | B2B, professionals | Articles, posts, video | Thought leadership, B2B lead gen | Engagement rate, InMail response |
| **Facebook/Instagram** | B2C, wide audience | Images, Reels, Stories, Shopping | Brand awareness, social commerce | Reach, engagement, shop conversion |
| **Twitter/X** | Real-time, tech, media | Threads, polls, Spaces | Thought leadership, PR, support | Engagement rate, retweet ratio |

| **Reddit** | Niche communities | Text posts, AMAs | Community building, product feedback | Karma, comment quality |

|-------------|-------------|----------|--------|-----------|
| Blog posts | Awareness, Consideration | Organic traffic, education | Thấp-TB | Cao |
| Guides/eBooks | Consideration | Lead generation, authority | Cao | Cao |
| Case studies | Consideration, Decision | Social proof, persuasion | Trung bình | Trung bình |
| Whitepapers | Consideration | Thought leadership | Cao | Trung bình |

| Templates/Tools | Consideration | Lead gen, utility | Trung bình | Cao |

### Content Production Workflow Requirements

| Phase | System Features Cần | Roles |
|-------|---------------------|-------|
| Ideation | Keyword research integration, content gap analysis, competitor monitoring | Content Manager |
| Brief | Template library, SEO requirements auto-fill, asset specifications | Content Manager |
| Creation | Editor with SEO suggestions, media library, version control | Writer/Designer |
| Review | Inline comments, approval workflow, brand checklist auto-check | Editor, Manager |
| Approval | Multi-level approval (content → legal → publish), audit trail | Manager, Legal |
| Publish | CMS integration, scheduling, SEO metadata auto-optimization | Content Manager |
| Distribute | Multi-channel push (social, email, paid), UTM auto-tagging | Campaign Specialist |
| Measure | Content performance dashboard, organic traffic attribution, conversion tracking | Marketing Analyst |

### Content Repurposing Strategy

```
Blog Post (gốc)
├── → Social media posts (5-10 posts)
├── → Email newsletter excerpt
├── → Infographic (key data points)
├── → Video script (3-5 phút)
├── → Podcast talking points
├── → Carousel slides (LinkedIn/Instagram)
└── → Thread format (Twitter/X)
```

## 4. Email Marketing

### Email Types & Requirements

| Loại email | Trigger | Consent cần | Tần suất | Metrics |
|-----------|---------|-------------|----------|---------|
| Welcome series | Sign-up | Marketing opt-in | 3-5 emails / 2 tuần | Open rate, activation |
| Newsletter | Scheduled | Marketing opt-in | Weekly/Bi-weekly | Open rate, CTR |
| Promotional | Campaign | Marketing opt-in | Max 2-3/tuần | Conversion rate, revenue |
| Nurture sequence | Lead score trigger | Marketing opt-in | Varies by segment | MQL conversion rate |
| Re-engagement | Inactivity trigger | Marketing opt-in | 1 series | Reactivation rate |
| Transactional | User action | Không cần (hệ thống) | Per event | Delivery rate |
| Abandoned cart | Cart abandonment | Marketing opt-in | 2-3 emails | Recovery rate |

### Email Deliverability Requirements

| Yêu cầu | Mô tả | System Support |
|---------|--------|----------------|
| SPF/DKIM/DMARC | Email authentication | DNS configuration |
| List hygiene | Bounce removal, inactive cleanup | Auto-list management |
| Unsubscribe | One-click unsubscribe (RFC 8058) | Template requirement |
| Frequency capping | Giới hạn số email/người/tuần | System rule |
| Reputation monitoring | IP/domain reputation tracking | Dashboard + alert |
| Preference center | Cho user chọn loại email nhận | Self-service portal |

### Email Personalization Levels

| Level | Mô tả | Ví dụ | Complexity |
|-------|--------|-------|-----------|
| Basic | Merge tags | "Xin chào {first_name}" | Thấp |
| Segment | Content by segment | Industry-specific offers | Trung bình |
| Behavioral | Content by actions | "Bạn đã xem sản phẩm X" | Cao |
| Dynamic | Real-time content blocks | Personalized product recommendations | Rất cao |
| AI-driven | Predictive content, send-time optimization | ML-based subject lines, optimal timing | Rất cao |

```
Account
└── Campaign (Mục tiêu: Awareness / Consideration / Conversion)
```

## Quick Reference: Platform-Specific Content Rules

| Platform | Hook | Độ dài tối ưu | Format | Tần suất đăng |
|----------|------|---------------|--------|---------------|
| LinkedIn | Strong opinion / data point | 150-300 words | Text + image, carousel, article | 3-5/tuần |
| Instagram | Visual-first | Caption < 125 chars (fold) | Reels 15-30s, carousel 5-10 slides | 1-2/ngày |
| Twitter/X | Hot take / question | < 280 chars | Thread 5-10 tweets, polls | 3-5/ngày |
| TikTok | Hook trong 3 giây | 15-60 giây | Vertical video 9:16 | 1-3/ngày |
| Blog/SEO | Answer search intent | 1500-3000 words | Long-form + headings + media | 2-4/tuần |
| Email | Subject line < 50 chars | 200-500 words body | HTML responsive | 1-3/tuần |
