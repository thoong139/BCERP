# Healthcare User Personas

> Reference file cho healthcare-expert agent
> Load file này khi cần hiểu về users trong domain Healthcare

## Danh sách Personas

### 1. Physician / Doctor

**Profile:**
- Chức danh: Physician / Doctor / Bác sĩ
- Kinh nghiệm: Varies (Resident to Attending)
- Technical skill: Medium
- Tần suất sử dụng hệ thống: All day, every patient

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Review patient records | Per patient | 5-10 min |
| Document encounters | Per patient | 10-15 min |
| Order tests/medications | Per patient | 5 min |
| Review results | Per patient | 5-10 min |
| Communicate with care team | Ongoing | Variable |

**Key Information Needed:**
- Patient history
- Current medications
- Allergies
- Lab/test results
- Imaging
- Clinical guidelines

**Pain Points:**
1. **Time consuming documentation**: Takes away from patient care
2. **Information overload**: Too much data, hard to find what's needed
3. **System slowdowns**: Waiting for system to respond
4. **Multiple logins**: Different systems require separate authentication
5. **Alert fatigue**: Too many irrelevant alerts

---

### 2. Nurse

**Profile:**
- Chức danh: Nurse / Registered Nurse / Y tá
- Kinh nghiệm: Entry to Senior level
- Technical skill: Medium
- Tần suất sử dụng hệ thống: Continuous throughout shift

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Medication administration | Per schedule | 5-10 min/patient |
| Vital signs documentation | Every 4-8 hours | 5 min/patient |
| Care documentation | Ongoing | Throughout shift |
| Order verification | As needed | 5-10 min |
| Patient education | Per patient | 10-30 min |

**Key Information Needed:**
- Medication administration record (MAR)
- Allergies
- Care plan
- Orders
- Patient status

**Pain Points:**
1. **Documentation burden**: Takes time from patient care
2. **Workstation scarcity**: Not enough computers
3. **Alert overload**: Desensitized to warnings
4. **Interrupted workflows**: Can't complete tasks in one session
5. **Duplicate entry**: Same info in multiple places

---

### 3. Patient

**Profile:**
- Độ tuổi: All ages
- Technical skill: Varies
- Channel: Patient portal, mobile app, kiosk

**Tasks:**
| Task | Frequency |
|------|-----------|
| Schedule appointments | As needed |
| View test results | After tests |
| Request prescription refills | As needed |
| Communicate with providers | As needed |
| View medical records | Occasionally |
| Pay bills | Monthly |

**Pain Points:**
1. **Portal complexity**: Hard to navigate
2. **Delayed results**: Waiting for information
3. **Communication gaps**: Can't reach providers
4. **Billing confusion**: Don't understand charges
5. **Multiple portals**: Different systems for different providers

---

### 4. Medical Coder / Biller

**Profile:**
- Chức danh: Medical Coder / Billing Specialist
- Kinh nghiệm: Mid level
- Technical skill: High
- Tần suất sử dụng hệ thống: Daily (full day)

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Review clinical documentation | Per encounter | 10-15 min |
| Assign diagnosis codes (ICD-10) | Per encounter | 5-10 min |
| Assign procedure codes (CPT) | Per encounter | 5-10 min |
| Submit claims | Per encounter | 5 min |
| Follow up on denials | Ongoing | Variable |

**Key Information Needed:**
- Clinical documentation
- Coding guidelines
- Payer rules
- Fee schedules
- Claim status

**Pain Points:**
1. **Incomplete documentation**: Missing information for coding
2. **Coding changes**: Frequent updates to learn
3. **Payer differences**: Different rules for each payer
4. **Denial volumes**: High denial rates to work
5. **Productivity pressure**: High volume expectations

---

### 5. Healthcare Administrator

**Profile:**
- Chức danh: Hospital Administrator / Practice Manager
- Kinh nghiệm: Senior level
- Technical skill: Medium to High
- Tần suất sử dụng hệ thống: Daily

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Review operational metrics | Daily | 30 min |
| Manage staffing | Daily | 1-2 hours |
| Address compliance issues | Ongoing | Variable |
| Financial review | Weekly | 2 hours |
| Strategic planning | Ongoing | Variable |

**Key Metrics:**
- Patient satisfaction scores
- Length of stay
- Readmission rates
- Revenue cycle metrics
- Staff productivity

**Pain Points:**
1. **Data silos**: Information in separate systems
2. **Reporting delays**: Not real-time visibility
3. **Regulatory complexity**: Constant changes
4. **Resource constraints**: Budget and staff limitations
