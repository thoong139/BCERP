# E-commerce User Personas

> Reference file cho ecommerce-expert agent
> Load file này khi cần hiểu về users trong domain E-commerce

## Danh sách Personas

### 1. Online Shopper (B2C Customer)

**Profile:**
- Chức danh: End consumer
- Độ tuổi: 18-65
- Technical skill: Varies (Low to High)
- Device: Mobile primary (70%), Desktop (30%)

**Shopping Behavior:**
| Behavior | Description |
|----------|-------------|
| Research | Compare prices, read reviews |
| Discovery | Search, browse categories, recommendations |
| Purchase | Add to cart, checkout, payment |
| Post-purchase | Track order, review, return |

**Pain Points:**
1. **Slow site**: Pages load too slowly
2. **Complicated checkout**: Too many steps, forced registration
3. **Hidden costs**: Surprise shipping, taxes at checkout
4. **Poor mobile experience**: Hard to navigate on phone
5. **No trust signals**: Reviews, security badges missing

**Must-have Features:**
- Fast page load (<3 seconds)
- Guest checkout option
- Clear pricing with all costs upfront
- Mobile-optimized design
- Trust badges and reviews

### 2. Seller / Merchant (Marketplace)

**Profile:**
- Chức danh: Seller / Vendor / Merchant
- Kinh nghiệm: Varies
- Technical skill: Low to Medium
- Tần suất sử dụng: Daily

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Manage product listings | Daily | 1-2 hours |
| Process orders | Multiple/day | 30 min-1 hour |
| Update inventory | Daily | 30 min |
| Respond to customer questions | Multiple/day | 1-2 hours |
| Analyze sales performance | Weekly | 1 hour |

**Pain Points:**
1. **Complex onboarding**: Hard to start selling
2. **Listing management**: Bulk updates difficult
3. **Order management**: Multiple platforms, scattered
4. **Fee structure**: Unclear commission calculations
5. **Visibility**: Products not appearing in search

---

### 3. E-commerce Operations Manager

**Profile:**
- Chức danh: E-commerce Manager / Operations Manager
- Kinh nghiệm: Mid to Senior level
- Technical skill: Medium to High
- Tần suất sử dụng: Daily (full day)

**Daily Tasks:**
| Task | Frequency | Time Spent | Priority |
|------|-----------|------------|----------|
| Monitor order status | Multiple/day | 30 min | High |
| Review inventory alerts | Daily | 30 min | High |
| Coordinate with warehouse | Daily | 1 hour | High |
| Handle escalations | As needed | Variable | High |
| Analyze sales metrics | Daily | 1 hour | Medium |

**Key Decisions:**
| Decision | Based On | System Support |
|----------|----------|----------------|
| Inventory replenishment | Stock levels, sales velocity | Inventory dashboard |
| Promotional pricing | Competition, margins | Pricing tools |
| Shipping partner selection | Cost, speed, reliability | Rate comparison |

**Pain Points:**
1. **Multi-channel sync**: Inventory across platforms
2. **Order exceptions**: Returns, failed deliveries
3. **Promotion management**: Complex discount rules
4. **Performance visibility**: Real-time metrics lacking

---

### 4. Customer Service Agent

**Profile:**
- Chức danh: CS Agent / Support Staff
- Kinh nghiệm: Entry level
- Technical skill: Medium
- Tần suất sử dụng: Daily (full day)

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Handle customer inquiries | 50-100/day | Most of day |
| Process return requests | 10-20/day | 5 min each |
| Track order issues | 10-15/day | 10 min each |
| Escalate complex issues | 5-10/day | 15 min each |

**Required Information:**
- Order history
- Customer details
- Product information
- Shipping status
- Return/refund history

**Pain Points:**
1. **Scattered information**: Multiple systems to check
2. **No context**: Missing customer history
3. **Limited authority**: Can't resolve many issues
4. **Channel switching**: Customers use multiple channels

---

### 5. Content Manager

**Profile:**
- Chức danh: Content Manager / PIM Manager
- Kinh nghiệm: Mid level
- Technical skill: Medium
- Tần suất sử dụng: Daily

**Daily Tasks:**
| Task | Frequency | Time Spent |
|------|-----------|------------|
| Update product content | Daily | 2-3 hours |
| Manage product images | Daily | 1 hour |
| Optimize SEO content | Weekly | 2 hours |
| Review category structure | Monthly | 3 hours |

**Pain Points:**
1. **Bulk updates**: No efficient way to update many products
2. **Image management**: Resizing, optimizing manually
3. **Attribute management**: Inconsistent product attributes
4. **Multi-channel publishing**: Different format requirements
