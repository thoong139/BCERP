# Customer Journey Mapping

> Reference file cho customer-expert agent
> Load file này khi cần map customer journey

## Journey Mapping Process

```
1. DEFINE stages
2. Identify touchpoints
3. Map customer emotions
4. Identify moments of truth
5. Document pain points & opportunities
```

## Customer Stages

| Stage | Description | Customer Goal |
|-------|-------------|----------------|
| Awareness | First contact with brand | Learn about options |
| Consideration | Researching solutions | Evaluate alternatives |
| Purchase | Making a decision | Buy product/service |
| Onboarding | Getting started | Learn to use effectively |
| Adoption | Regular usage | Get value from product |
| Retention | Staying engaged | Continue using product |
| advocacy | Recommending | Share positive experience |

---

## Touchpoint Categories
| Type | Examples |
|------|---------|
| Website | Homepage, product pages, blog, checkout |
| Mobile app | Onboarding, features, support |
| Customer service | Call, email, chat, in-person |
| Marketing | Emails, social media, ads |
| Sales | Sales calls, demos, proposals |
| Billing | Invoices, payment pages |
| Post-purchase | Surveys, reviews, follow-up emails |

---

## Emotion Mapping

| Customer Emotion | System Response |
|------------------|----------------------|
| Frustrated | Friction, blockers | Simplify, remove friction |
| Confused | Unclear information | Clarify, guide, help |
| Anxious | Uncertainty | Provide reassurance, social proof |
| Delighted | Success achieved | Celebr, share |
| Angry | Problem encountered | Apologize, resolve quickly |
| Neutral | Just okay | No emotion | Engage, seek feedback |

## Quick Start
1. Identify stages (3-5)
2. List touchpoints for each stage
3. Map customer journey (linear progression)
4. Identify pain points with emojis
5. Document opportunities
