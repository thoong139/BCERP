## Academic Calendar & Enrollment Cycle

### Cấu trúc năm học (VN phổ thông & ĐH)
| Kỳ | Thời gian | Nội dung |
|----|-----------|----------|
| Học kỳ 1 | Sep – Jan | Kỳ học chính |
| Học kỳ 2 | Feb – Jun | Kỳ học chính |
| Học hè | Jul – Aug | Bổ sung, cải thiện điểm |

### Enrollment Timeline
```
Enrollment window:  4-6 tuần trước khi học kỳ bắt đầu
Add/Drop period:    1-2 tuần đầu học kỳ (thêm/bỏ môn)
Final exam period:  2-3 tuần cuối học kỳ
Grade posting:      2 tuần sau khi thi xong
Grade appeal:       1 tuần sau khi điểm publish
```

## Course Lifecycle (8 bước)

```
1. Course Design
   └── Curriculum committee review → Course catalog approval

2. Content Creation
   └── Instructor develops materials → Upload to LMS → QA check

3. Scheduling
   └── Admin assigns: time slots + rooms + instructors (conflict check)

4. Enrollment
   └── Students register → Class formed → Waitlist if full → Confirmation sent

5. Content Delivery
   └── Lectures, labs, online modules, live sessions (Zoom/Meet)

6. Assessment
   └── Quizzes + Assignments + Midterm exam + Final exam

7. Grading
   └── Instructor grades → Department Head review → Grade posting → Lock

8. Certification / Transcript
   └── Auto-generate after grade finalized + requirements met
```

## LMS Content Types

| Type | Format | Notes |
|------|--------|-------|
| Video | MP4 (hosted hoặc YouTube/Vimeo embed) | Subtitles, resume position, speed control |
| Document | PDF, PPT, Word | Version control, download control |
| Quiz | Multiple choice, true/false, fill-blank | Auto-graded, time limit, attempt limit |
| Assignment | File submission, peer review | Rubric-based grading, plagiarism check |
| Live Session | Zoom/Google Meet integration | Auto-create meeting, attendance recorded |
| SCORM | Third-party content packages | SCORM 1.2 và 2004, completion/score tracking |
| Discussion | Forum, Q&A, peer interaction | Moderated by instructor |

## Assessment & Grading Process

### Grading Scales
| Scale | Used for |
|-------|----------|
| 10-point (0-10) | VN standard (phổ thông, đại học công lập) |
| Letter grade (A/B/C/D/F) | International programs |
| Pass/Fail | Corporate compliance training |

### Weighted Average (mẫu — configurable)
```
Attendance:  10%
Assignments: 20%
Midterm:     30%
Final exam:  40%
```

### Grade Appeal Process
```
Student submits appeal (within 1 week of posting)
→ Instructor review (3 days)
→ Department Head final decision
→ If approved: grade updated → re-lock
→ After appeal window: no changes allowed
```

### Academic Standing
| GPA | Status |
|-----|--------|
| ≥ 3.0 | Good Standing |
| 2.0 – 2.99 | Academic Warning |
| < 2.0 (1 kỳ) | Probation |
| < 2.0 (2 kỳ liên tiếp) | Dismissal Review |

## Enrollment & Admission Workflow

```
Application
└── Online form → Document upload → Application fee payment

Screening
└── Academic requirement check → Entrance test (if required) → Interview

Offer
└── Acceptance letter generated → Student accepts → Initial payment

Registration
└── Student profile created → ID card generated → LMS account provisioned

Orientation
└── Schedule sent → Resources shared → Welcome email
```

## KPIs

### Learning Effectiveness
| KPI | Formula | Target |
|-----|---------|--------|
| Completion Rate | % students who complete course | > 85% |
| Pass Rate | % students who pass (≥ threshold) | > 90% |
| Average Score | Mean score across assessments | Benchmark per course |
| Time to Certificate | Avg days from enrollment to certificate | < SLA per course type |

### Operational KPIs
| KPI | Formula | Target |
|-----|---------|--------|
| Attendance Rate | % sessions attended per student | > 80% |
| Teacher Utilization | % time teaching vs admin | > 70% teaching |
| Grade Posting Compliance | % grades posted on time | 100% |
| Enrollment Fill Rate | Enrolled / Max capacity | 80-100% |

### Experience KPIs
| KPI | Target |
|-----|--------|
| Student Satisfaction (NPS) | > 50 |
| Parent App DAU | Track trending |
| Support Ticket Resolution | < 24h first response |

### Commercial (training centers)
| KPI | Notes |
|-----|-------|
| Revenue per Student | Monthly/annual |
| Student Retention Rate | % re-enroll next term |
| Referral Rate | % new students from referral |
