# i18n Rules

## 1. Translation Pattern

- Dùng `useTranslations('module')` hook (client) hoặc `getTranslations` (server)
- KHÔNG hardcode strings trong UI: `<h1>{t('title')}</h1>` thay vì `<h1>Quản lý</h1>`

## 2. Translation Keys

```
messages/
├── en.json    ← Base language
└── vi.json    ← Vietnamese
```

Key pattern: `{module}.{section}.{item}` — VD: `customers.list.empty`

## 3. Formatting

- Number/Currency/Date: Dùng locale-aware functions từ `@/shared/i18n`
- KHÔNG hardcode format: `formatCurrency(amount, { currency: 'VND', locale })` thay vì `amount.toLocaleString('vi-VN')`
- Pluralization: ICU format `{count, plural, =0 {No items} =1 {1 item} other {# items}}`

## 4. Validation & API Errors

- Validation messages phải i18n: `z.string().min(1, t('required', { field }))`
- API error codes map sang translated messages
- Language persistence: cookie `locale`, max-age 1 năm
