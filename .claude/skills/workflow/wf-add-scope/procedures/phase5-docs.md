- `scope-spec.features_to_add` non-empty

**Condition check + early exit:**

```
IF $DRY_RUN == true:
  UPDATE add-scope-status.json: phase_5.status = "skipped (--dry-run)"

IF $NO_DOCS == true:
  SKIP Phase 5 entirely

IF features_count == 0:
```

**Behavior matrix:**

| Mode | `features_to_add` | Phase 5 behavior |

### Step 5.2-5.4 — [PAR] PARALLEL per feature (Template Usage Rule)

**Execution mode:** PARALLEL (mỗi file độc lập).

```
FOR each feature IN features_to_add ([PAR] PARALLEL):
  feat    = feature
  module  = modules_to_add WHERE id == feat.module_id

  # 📋 Template Usage Rule: READ → POPULATE → WRITE
  READ templates/feature-stub.md

  POPULATE placeholders:
    [FEAT-ID]            → feat.id
    [Feature Name]       → feat.name
    [MODULE-ID]          → feat.module_id
    [SYSTEM-ID]          → $SYSTEM_ID
    [CODE_REF]           → feat.code_refs[0]
    [REQ-ID-LIST]        → feat.req_ids.join(", ")
    [DEPT-LIST]          → module.depts.join(", ")
    [PARENT_MOD_ID]      → feat.module_id
    [PARENT_BACKEND_MOD] → module.depends_on[0] hoặc "N/A"
    [N files detected]   → count files trong code_refs
    [Tech stack]         → detect từ project-context.json hoặc "N/A"
    cross_system         → "true" nếu UI depends on backend

  # Ensure STUB banner (PREPEND nếu template chưa có)
  PREPEND: "> **[STUB AUTO-GENERATED BY /wf-add-scope]** — Review và flesh-out cần thiết."

  # Compute output path
  sys_slug   = $SYSTEM_ID lowercase + replace "-" for path
  mod_slug   = module.id lowercase
  feat_slug  = feat.id lowercase
  output_path = ".mc-data/docs/phase2-features/[sys-slug]/[mod-slug]/[feat-slug].md"

  # Conflict check (CORE-020 spirit — don't overwrite user content)
  IF exists(output_path) AND nội dung KHÔNG chứa "[STUB AUTO-GENERATED BY /wf-add-scope]":
    INCREMENT $STUBS_SKIPPED
    LOG warning E007: "Path conflict (non-stub) — skipped: $output_path"
    CONTINUE

  mkdir -p dirname(output_path)
  WRITE output_path
  INCREMENT $STUBS_CREATED
```
