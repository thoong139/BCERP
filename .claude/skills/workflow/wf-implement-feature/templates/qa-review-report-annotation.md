## Annotation Checklist (focused)

> Chỉ check những điểm liên quan đến annotation. Bỏ qua DRY/SOLID/imports/naming nếu không touch logic.

### Header Format Compliance

- [ ] Mỗi file có EXACTLY 2 header lines: `// REQ-ID: REQ-XXX-NNN` + `// FEAT-ID: FEAT-XXX-NNN`
- [ ] Không có duplicate header lines (e.g. 2x `// REQ-ID:`)
- [ ] Không có invalid values: `null`, `undefined`, `[REQ-XXX]`, empty string
- [ ] REQ-ID format đúng: `REQ-[A-Z]+-[A-Z0-9-]+` (regex)
- [ ] FEAT-ID format đúng: `FEAT-[A-Z]+-[A-Z0-9-]+`

### REQ-ID Match với Registry

- [ ] REQ-ID trong header khớp với `req-registry.json.features[].req_ids[]`
- [ ] FEAT-ID trong header khớp với `req-registry.json.features[].id`
- [ ] Không reference REQ-ID đã `impl_status: "skipped"`

### Scope Discipline (Finding #19, #20)

- [ ] Annotation-only batch CHỈ sửa header lines (không touch function bodies, exports, imports)
- [ ] Section dividers/inline references (`─── Module — FEAT-ID ───`) đã được PRESERVE unchanged
- [ ] Không có logic change "trộn" vào batch annotation
