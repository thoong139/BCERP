## §A Header

Lane CD13 đảm bảo **FE API client calls khớp BE endpoint contracts** (route + HTTP method + path params + response shape). Root cause #1 cho 4xx errors production khi BE rename route/method nhưng FE chưa update.

**Vì sao quan trọng:**
- FE_CALLS_NONEXISTENT_BE_ENDPOINT → 404 guaranteed
- HTTP_METHOD_MISMATCH → 405 Method Not Allowed guaranteed
- ENDPOINT_PARAM_MISSING → 400/404 invalid request
- BE_ENDPOINT_UNUSED_BY_FE → có thể dead code BE hoặc public API (low severity, không cấm)

**Reference design canon:** `docs/04-skill-design/wf-cmi/agent-prompt.md §20`

### Step CD13.2 — Normalize route patterns (preparation)

> Route normalization: `/api/v1/crm/customers/{id}` ~ `/api/v1/crm/customers/{id:int}` ~ `/api/v1/crm/customers/:id` → canonical form.

**Logic:**
```bash
# Pseudo-code: build lookup map for BE endpoints
# Key: METHOD + normalized_path → endpoint_node
# Normalize: lowercase + strip :type/?regex + replace :param với {param}
```

Store in `$LANE_DIR/.be-endpoint-map.json` (temporary helper file, removed after lane).

### Step CD13.3 — FE→BE endpoint existence (FE_CALLS_NONEXISTENT_BE_ENDPOINT)

> Mỗi FE node với `endpoint_path != null` phải tìm thấy BE endpoint tương ứng.

**Logic:**
1. Iterate `fe-api-client-graph.nodes[]` filter `endpoint_path != null AND endpoint_method != null`
2. Normalize FE endpoint_path same algorithm Step CD13.2
3. Lookup `{endpoint_method}:{normalized_path}` trong BE endpoint map
4. Không tìm thấy → FE_CALLS_NONEXISTENT_BE_ENDPOINT (severity MUST — chắc chắn 404)

**Signal payload:**
```json
{
  "kind": "FE_CALLS_NONEXISTENT_BE_ENDPOINT",
  "severity": "MUST",
  "category": "VIOLATION",
  "rule_id": "FEBE-CD13-001",
  "message": "FE useGetCustomers gọi GET /api/v1/crm/customers nhưng BE chưa register endpoint này",
  "affected_entities": ["useGetCustomers"],
  "affected_files": ["apps/erp-web/lib/api/customer-client.ts"],
  "evidence": [{"file": "apps/erp-web/lib/api/customer-client.ts", "line": 12, "snippet": "useQuery({ queryKey: ['customers'], queryFn: () => fetch('/api/v1/crm/customers') })"}],
  "suggested_action": "Verify BE controller exists hoặc update FE endpoint path. Check: apps/backend/Eureka.Modules.Crm/Customers/Controllers/CustomersController.cs."
}
```

### Step CD13.4 — BE endpoint coverage (BE_ENDPOINT_UNUSED_BY_FE)

> Mỗi BE endpoint không có FE caller — có thể dead code hoặc public API legacy.

**Logic:**
1. Build set of FE endpoint pairs (METHOD + normalized_path)
2. Iterate `api-graph.endpoints[]`
3. Endpoint không trong FE set → BE_ENDPOINT_UNUSED_BY_FE (severity MAY)
4. Skip endpoints trong `exclusions[]` của ui-interactivity-spec.json (nếu populated) — webhook/admin-only

**Rule ID:** `FEBE-CD13-002`

**Note:** Severity MAY vì có thể BE expose public API (mobile/third-party), không cấm hard. Output làm signal RECOMMENDATION category để Phase 7 triage.

### Step CD13.5 — HTTP method mismatch (HTTP_METHOD_MISMATCH)

> FE và BE cùng route nhưng khác method → 405 guaranteed.

**Logic:**
1. Iterate FE nodes có endpoint_path + endpoint_method
2. Lookup BE endpoint by `normalized_path` only (không match method)
3. Nếu có BE endpoint cùng path nhưng khác method → HTTP_METHOD_MISMATCH (severity MUST)

**Rule ID:** `FEBE-CD13-003`

**Edge case:** BE có 2 endpoints cùng path khác method (vd GET + POST `/api/customers`) — chỉ flag nếu FE method không trong set BE methods.

### Step CD13.6 — Path param coverage (ENDPOINT_PARAM_MISSING)

> Route pattern có `{param}` nhưng FE không pass.

**Logic:**
1. Parse route pattern: `/api/customers/{id}` → params=["id"]
2. Check FE node: client name hoặc enclosing function context có hint "id" parameter
   - Heuristic: client function signature parsable từ name (vd `useGetCustomerById(id)` → có "id")
   - Hoặc grep file_path tìm parameter binding
3. Path param không được FE bind → ENDPOINT_PARAM_MISSING (severity SHOULD)

**Rule ID:** `FEBE-CD13-004`

**Limitation v1.0:** Heuristic Grep-based — FE wrapper với generic name (vd `useCustomer()`) sẽ bị false positive. v2.1 ts-morph AST sẽ chính xác hơn.

### Step CD13.7 — DTO shape drift (DTO_SHAPE_DRIFT) [optional, low confidence]

> FE response shape ≠ BE return shape. Heuristic-only, flag chỉ confidence cao.

**Logic:**
1. Iterate matched FE↔BE pairs (passed Step CD13.3-CD13.5)
2. Extract FE expected shape từ TypeScript type (heuristic — useQuery `<TData>` generic)
3. Extract BE return shape từ controller action return type
4. Compare top-level keys (không deep diff v1.0)
5. Field mismatch ≥3 → DTO_SHAPE_DRIFT (severity MAY)

**Rule ID:** `FEBE-CD13-005`

**Note:** v1.0 disable mặc định nếu thiếu type info — chỉ enable khi cả 2 graph có `response_type` field. v2.1 deep DTO comparison.

### Step CD13.8 — Write signals.json (Atomic Write)

```bash
SIGNALS_TMP="$LANE_DIR/.signals.tmp.$$"

jq -n \
  --arg sid "$SESSION_ID" \
  --arg ts "$(date -Iseconds)" \
  --arg lane "CD13" \
  --arg agent "architect" \
  --arg scope_type "$SCOPE_TYPE" \
  --argjson signals "$ALL_SIGNALS_JSON" \
  --argjson modules_covered "$MODULES_COVERED" \
  --arg ci "$CI_SOURCE" \
  '{
    "$schema": "signals-v1",
    "session_id": $sid,
    "generated_at": $ts,
    "lane": $lane,
    "agent_subagent_type": $agent,
    "scope": {"type": $scope_type, "modules": $modules_covered},
    "status": "COMPLETED",
    "scan_duration_sec": ($scan_duration | tonumber),
    "signals": $signals,
    "metadata": {
      "signal_count": ($signals | length),
      "severity_breakdown": {
        "MUST": ([$signals[] | select(.severity == "MUST")] | length),
        "SHOULD": ([$signals[] | select(.severity == "SHOULD")] | length),
        "MAY": ([$signals[] | select(.severity == "MAY")] | length),
        "INFO": ([$signals[] | select(.severity == "INFO")] | length)
      },
      "category_breakdown": {
        "MISSING_INVARIANT": ([$signals[] | select(.category == "MISSING_INVARIANT")] | length),
        "VIOLATION": ([$signals[] | select(.category == "VIOLATION")] | length),
        "GAP": ([$signals[] | select(.category == "GAP")] | length),
        "RECOMMENDATION": ([$signals[] | select(.category == "RECOMMENDATION")] | length)
      },
      "modules_covered": $modules_covered,
      "ci_source": $ci,
      "fallback_used": false
    }
  }' > "$SIGNALS_TMP"

jq '.' "$SIGNALS_TMP" >/dev/null || die "E044" "signals.json invalid JSON"
mv "$SIGNALS_TMP" "$LANE_DIR/signals.json"

# Cleanup helper file
rm -f "$LANE_DIR/.be-endpoint-map.json"
```

## §D POST-GATE (T1→T4 + Auto-Fix)

| Tier | Check | Tool | Fail action |
|------|-------|------|-------------|
| T1 | `signals.json` + `CD13-fe-be-contract-sync-report.md` + `lane-status.json` exist | bash | **E044** — Output missing → auto-fix retry x3 |
| T2 | `signals.json` schema = `signals-v1`, `lane` = "CD13", fingerprint unique | jq | **E044** — Schema invalid → re-build |
| T3 | Mọi signal `rule_id` match format `FEBE-CD13-\d{3}` (001-005) | jq | **E045** — Format invalid → re-render |
| T4 | `affected_files[]` mỗi signal resolve trong fe-api-client-graph hoặc api-graph nodes | jq | **E045** — File unresolved → log WARN |

```bash
# T1
for f in signals.json CD13-fe-be-contract-sync-report.md lane-status.json; do
  [ -f "$LANE_DIR/$f" ] || die "E044" "Output missing: $f"
done

# T2
SCHEMA=$(jq -r '."$schema"' "$LANE_DIR/signals.json")
LANE_VAL=$(jq -r '.lane' "$LANE_DIR/signals.json")
[ "$SCHEMA" = "signals-v1" ] || die "E044" "Schema mismatch"
[ "$LANE_VAL" = "CD13" ] || die "E044" "Lane field mismatch"

FP_TOTAL=$(jq '.signals | length' "$LANE_DIR/signals.json")
FP_UNIQUE=$(jq '[.signals[].fingerprint] | unique | length' "$LANE_DIR/signals.json")
[ "$FP_TOTAL" = "$FP_UNIQUE" ] || die "E044" "Fingerprint collision: $FP_TOTAL vs $FP_UNIQUE"

# T3
INVALID_RULES=$(jq -r '[.signals[] | select(.rule_id | test("^FEBE-CD13-[0-9]{3}$") | not) | .rule_id] | length' "$LANE_DIR/signals.json")
[ "$INVALID_RULES" = "0" ] || die "E045" "Invalid rule_id format count: $INVALID_RULES"

# T4
UNRESOLVED=$(jq -r --slurpfile fe "$FE_API" --slurpfile be "$BE_API" \
  '[.signals[] | .affected_files[]?] | unique
   | map(select(. as $f |
       ($fe[0].nodes | map(.file_path) | index($f)) == null
       and ($be[0].endpoints // $be[0].nodes | map(.file_path // .controller_file) | index($f)) == null))
   | length' "$LANE_DIR/signals.json")
[ "$UNRESOLVED" = "0" ] || log_warn "E045" "Unresolved files count: $UNRESOLVED"
```

**Auto-fix budget (CORE-034):** Max 3 retries. Hết → ESCALATE FAIL.
