## §A Header

Lane CD17 đảm bảo **tính nhất quán của persistence layer** trong codebase backend EF Core .NET — DB schema khớp Entity, migration không drift, FK có index, không có dead column. Sub-stage 4.2 BE deep lane phức tạp do cần cross-ref 2 graph layers (DB schema từ EF migrations + Entity từ DDD codebase).

**Vì sao quan trọng:**
- Migration drift → DbContextModelSnapshot stale → deployment scripts generate wrong SQL → production data loss
- Missing FK index → JOIN/filter by FK table scan → query time tăng 10-100x ở scale
- Schema mismatch entity vs DB → ORM mapping fail runtime → app crash OR silent data truncation (vd float thay decimal cho Money)
- Unused table column → orphan data accumulate, technical debt + GDPR risk (PII column không track)

### Step CD17.2 — Migration drift detection (MIGRATION_DRIFT)

> DbContextModelSnapshot.cs phải có timestamp ≥ latest migration file trong filesystem.

**Logic:**
1. Lấy `last_migration_per_module{}` từ graph metadata (build từ DbContextModelSnapshot)
2. Glob filesystem cho migration files: `apps/backend/**/Migrations/[0-9]*_*.cs` (exclude `*Designer.cs` + `*ModelSnapshot.cs`)
3. For each module:
   - Extract timestamp prefix từ filename (vd `20260515123045_AddCustomerTable.cs` → `20260515123045`)
   - Find max timestamp trong filesystem cho module
   - Compare với `last_migration_per_module[module]` (extract timestamp tương tự)
   - Nếu filesystem_max > snapshot_last → MIGRATION_DRIFT (severity MUST)
4. Edge case: nếu graph dùng EUREKA shared DbContext (`Infrastructure` module aggregates), check chỉ 1 entry "Infrastructure" map all modules

**Signal payload:**
```json
{
  "kind": "MIGRATION_DRIFT",
  "severity": "MUST",
  "category": "VIOLATION",
  "rule_id": "PERSIST-CD17-001",
  "message": "Module Infrastructure có migration mới hơn DbContextModelSnapshot — snapshot stale",
  "affected_entities": ["DbContextModelSnapshot"],
  "affected_files": [
    "apps/backend/Eureka.Migration/Migrations/20260515123045_AddCustomerTable.cs",
    "apps/backend/Eureka.Migration/Migrations/EurekaDbContextModelSnapshot.cs"
  ],
  "evidence": [
    {"latest_migration": "20260515123045_AddCustomerTable", "snapshot_last": "20260510084231_InitialCreate", "diff_count": 3}
  ],
  "suggested_action": "Chạy `dotnet ef migrations add NoOp --project apps/backend/Eureka.Migration` để regenerate snapshot, sau đó remove NoOp migration file để giữ history sạch."
}
```

### Step CD17.3 — Missing FK index (MISSING_INDEX)

> FK columns không có index → JOIN/filter performance issue (PostgreSQL không auto-create index cho FK).

**Logic:**
1. Iterate `tables[]`:
   - For each table: iterate `foreign_keys[]`
   - For each FK: get `columns[]` (array of FK column names)
   - Cross-ref `indexes[]` cùng table:
     - Tìm index có `columns[]` bao phủ FK columns (prefix match — index `(customer_id, status)` cover FK trên `customer_id`)
   - Không tìm thấy index → MISSING_INDEX (severity SHOULD)
2. Skip:
   - FK trùng với primary_key (PK đã được index)
   - Table trong `exclusions[]` (vd `__EFMigrationsHistory`, `_outbox_messages`)
   - Table có `metadata.estimated_rows < 100` (small table, table scan acceptable)

**Rule ID:** `PERSIST-CD17-002`

**Note:** Severity SHOULD vì v1.0 KHÔNG có row count estimate, dùng heuristic table name (lookup tables Currency/Country → skip).

### Step CD17.4 — Schema mismatch entity vs DB (SCHEMA_MISMATCH_ENTITY_DB)

> Entity property type/existence phải khớp với DB column.

**Logic:**
1. Skip step nếu HAS_DOMAIN_GRAPH=false (cần entity graph) — log WARN E133
2. Iterate ENTITIES (filter aggregate_root + entity từ be-domain-graph):
   - Normalize entity name → table name candidates (3 variants):
     - PascalCase same (`Customer` → `Customer`)
     - snake_case (`Customer` → `customer`)
     - pluralized snake (`Customer` → `customers`) — EF Core default convention
   - Find matching `tables[].name`
3. For each matched (entity, table) pair:
   - For each entity property (heuristic v1.0 — graph chỉ track `properties_count`, KHÔNG có property names cụ thể):
     - Lane CD17 v1.0 chỉ check existence ở `column_count` level: entity_property_count vs table_column_count
     - Nếu diff > 30% → suspect SCHEMA_MISMATCH (severity SHOULD)
   - v2.1: parser upgrade Roslyn track property names + types → full cross-ref
4. Edge cases:
   - Entity inheritance (TPH/TPT/TPC) — skip child entity check
   - Owned entities (`[Owned]` attribute) — share table với parent, skip
   - Computed properties (`[NotMapped]`) — không persist, skip diff

**Rule ID:** `PERSIST-CD17-003`

**Note:** v1.0 limitation rõ ràng — coverage indicator chỉ ở mức "table tồn tại không" thay vì "column type match không". v2.1 cần parser AST.

### Step CD17.5 — Unused table column (UNUSED_TABLE_COLUMN)

> DB column không map property nào của entity → dead column candidate.

**Logic:**
1. Skip step nếu HAS_DOMAIN_GRAPH=false
2. Iterate `tables[]`:
   - For each table: iterate `columns[]`
   - Skip whitelist technical columns: `created_at`, `updated_at`, `deleted_at`, `tenant_id`, `version`, `audit_*`, `is_deleted`, `created_by`, `updated_by`
   - Skip FK shadow properties: column name kết thúc `_id` AND có matching FK entry trong `foreign_keys[]`
   - Skip discriminator column (TPH inheritance): column tên `Discriminator` hoặc `type`
3. Cross-ref entity graph:
   - Find entity matching table name (normalize PascalCase/snake_case/pluralized)
   - v1.0 limitation: KHÔNG có property names — chỉ flag suspect khi `column_count > entity.properties_count + 5` (5 = buffer cho technical columns + FK)
4. → UNUSED_TABLE_COLUMN (severity MAY — dead column candidate, cần manual review)

**Rule ID:** `PERSIST-CD17-004`

**Note:** Severity MAY vì v1.0 dùng heuristic count thay vì exact match. False positive rate cao — agent runtime cần document trong evidence "v1.0 heuristic count-based, requires manual verify".

### Step CD17.6 — Write signals.json (Atomic Write)

```bash
SIGNALS_TMP="$LANE_DIR/.signals.tmp.$$"

jq -n \
  --arg sid "$SESSION_ID" \
  --arg ts "$(date -Iseconds)" \
  --arg lane "CD17" \
  --arg agent "dba" \
  --arg scope_type "$SCOPE_TYPE" \
  --argjson signals "$ALL_SIGNALS_JSON" \
  --argjson modules_covered "$MODULES_COVERED" \
  --arg ci "$CI_SOURCE" \
  --arg has_domain "$HAS_DOMAIN_GRAPH" \
  '{
    "$schema": "signals-v1",
    "session_id": $sid,
    "generated_at": $ts,
    "lane": $lane,
    "agent_subagent_type": $agent,
    "scope": {"type": $scope_type, "modules": $modules_covered},
    "status": "COMPLETED",
    "scan_duration_sec": ($scan_duration | tonumber),
    "signals": $signals,
    "metadata": {
      "signal_count": ($signals | length),
      "severity_breakdown": {
        "MUST": ([$signals[] | select(.severity == "MUST")] | length),
        "SHOULD": ([$signals[] | select(.severity == "SHOULD")] | length),
        "MAY": ([$signals[] | select(.severity == "MAY")] | length),
        "INFO": ([$signals[] | select(.severity == "INFO")] | length)
      },
      "category_breakdown": {
        "MISSING_INVARIANT": ([$signals[] | select(.category == "MISSING_INVARIANT")] | length),
        "VIOLATION": ([$signals[] | select(.category == "VIOLATION")] | length),
        "GAP": ([$signals[] | select(.category == "GAP")] | length),
        "RECOMMENDATION": ([$signals[] | select(.category == "RECOMMENDATION")] | length)
      },
      "modules_covered": $modules_covered,
      "ci_source": $ci,
      "has_domain_graph": ($has_domain == "true"),
      "fallback_used": false
    }
  }' > "$SIGNALS_TMP"

jq '.' "$SIGNALS_TMP" >/dev/null || die "E044" "signals.json invalid JSON"
mv "$SIGNALS_TMP" "$LANE_DIR/signals.json"
```

## §D POST-GATE (T1→T4 + Auto-Fix)

| Tier | Check | Tool | Fail action |
|------|-------|------|-------------|
| T1 | `signals.json` + `CD17-persistence-consistency-report.md` + `lane-status.json` exist | bash | **E044** — Output missing → auto-fix (re-run Step CD17.6-CD17.8 max 3) |
| T2 | `signals.json` schema = `signals-v1`, `lane` = "CD17", all signals có `fingerprint` unique | jq | **E044** — Schema invalid → auto-fix re-build từ raw signals |
| T3 | Mọi signal `rule_id` match format `PERSIST-CD17-\d{3}` (PERSIST-CD17-001 → PERSIST-CD17-004) | jq | **E045** — Rule_id format invalid → re-render từ template |
| T4 | `affected_entities[]` mỗi signal resolve được trong `be-db-schema-graph.json.tables[].name` HOẶC `be-domain-graph.json.nodes[].name` (nếu có) | jq | **E045** — Entity unresolved → log WARN (có thể là entity ngoài scope), KHÔNG block |

```bash
# T1 — Output files exist
for f in signals.json CD17-persistence-consistency-report.md lane-status.json; do
  [ -f "$LANE_DIR/$f" ] || die "E044" "Output missing: $f"
done

# T2 — Schema valid
SCHEMA=$(jq -r '."$schema"' "$LANE_DIR/signals.json")
LANE_VAL=$(jq -r '.lane' "$LANE_DIR/signals.json")
[ "$SCHEMA" = "signals-v1" ] || die "E044" "Schema mismatch: $SCHEMA != signals-v1"
[ "$LANE_VAL" = "CD17" ] || die "E044" "Lane field mismatch: $LANE_VAL != CD17"

# Fingerprint dedup
FP_TOTAL=$(jq '.signals | length' "$LANE_DIR/signals.json")
FP_UNIQUE=$(jq '[.signals[].fingerprint] | unique | length' "$LANE_DIR/signals.json")
[ "$FP_TOTAL" = "$FP_UNIQUE" ] || die "E044" "Fingerprint collision: total=$FP_TOTAL unique=$FP_UNIQUE"

# T3 — Rule ID format
INVALID_RULES=$(jq -r '[.signals[] | select(.rule_id | test("^PERSIST-CD17-[0-9]{3}$") | not) | .rule_id] | length' "$LANE_DIR/signals.json")
[ "$INVALID_RULES" = "0" ] || die "E045" "Invalid rule_id format count: $INVALID_RULES"

# T4 — Entity resolution (WARN only)
if [ "$HAS_DOMAIN_GRAPH" = "true" ]; then
  UNRESOLVED=$(jq -r --slurpfile db "$BE_DB_GRAPH" --slurpfile dom "$BE_DOMAIN_GRAPH" \
    '[.signals[] | .affected_entities[]?] | unique
     | map(select(. as $e | ($db[0].tables | map(.name) | index($e)) == null
                         and ($dom[0].nodes | map(.name) | index($e)) == null
                         and ($e != "DbContextModelSnapshot")))
     | length' "$LANE_DIR/signals.json")
else
  UNRESOLVED=$(jq -r --slurpfile db "$BE_DB_GRAPH" \
    '[.signals[] | .affected_entities[]?] | unique
     | map(select(. as $e | ($db[0].tables | map(.name) | index($e)) == null
                         and ($e != "DbContextModelSnapshot")))
     | length' "$LANE_DIR/signals.json")
fi
[ "$UNRESOLVED" = "0" ] || log_warn "E045" "Unresolved entities count: $UNRESOLVED (có thể ngoài be-db-schema-graph/be-domain-graph scope)"
```

**Auto-fix budget (CORE-034):** Max 3 retries — re-render template + re-populate signals. Hết budget → ESCALATE FAIL.
