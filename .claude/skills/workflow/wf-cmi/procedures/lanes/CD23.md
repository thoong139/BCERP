FE_COMP_NODES=$(jq -c '.nodes' "$FE_COMP_GRAPH")

### Step CD23.2 — Design token drift (DESIGN_TOKEN_DRIFT)

> Hardcoded color/spacing/font-size/border-radius trong components không match tokens.

**Logic:**
1. Iterate `fe-component-graph.nodes[]` filter file_path ngoài `exclusions.design_token[]`
2. For each file, Grep:
   - Color hex: `#[0-9a-fA-F]{3,8}` (vd `#FF5733`, `#fff`)
   - Color function: `rgb\(|rgba\(|hsl\(|hsla\(` literal calls
   - Hardcoded spacing: `padding:\s*\d+px|margin:\s*\d+px|gap:\s*\d+px|width:\s*\d+px` (excl. tailwind utility)
   - Hardcoded font-size: `font-size:\s*\d+(px|rem)` (excl. tailwind utility `text-{size}`)
3. Cross-ref với `DESIGN_TOKENS`:
   - Color hex/rgb value KHÔNG trong `colors.{primary,secondary,...}` palette → DESIGN_TOKEN_DRIFT (severity SHOULD)
   - Spacing value KHÔNG trong `spacing[]` scale → DESIGN_TOKEN_DRIFT (severity SHOULD)
   - Font-size KHÔNG trong `typography.font_sizes[]` → DESIGN_TOKEN_DRIFT (severity SHOULD)
4. Group nhiều violation cùng file → 1 signal với evidence array

**Signal payload:**
```json
{
  "kind": "DESIGN_TOKEN_DRIFT",
  "severity": "SHOULD",
  "category": "VIOLATION",
  "rule_id": "UXDS-CD23-001",
  "message": "Component CustomerCard hardcode 2 color value + 1 spacing không từ design tokens",
  "affected_entities": ["CustomerCard"],
  "affected_files": ["apps/erp-web/components/customer-card.tsx"],
  "evidence": [
    {"file": "apps/erp-web/components/customer-card.tsx", "line": 12, "snippet": "background: '#FF5733'", "drift_kind": "color"},
    {"file": "apps/erp-web/components/customer-card.tsx", "line": 18, "snippet": "padding: 13px", "drift_kind": "spacing"}
  ],
  "suggested_action": "Replace với tokens.colors.warning + tokens.spacing.md (xem .mc-data/docs/_meta/ux-conventions.json)"
}
```

### Step CD23.3 — Button/Badge variant inconsistent (BUTTON_VARIANT_INCONSISTENT)

> Component instance dùng variant không declared trong SSOT component_variants.

**Logic:**
1. Iterate `fe-component-graph.nodes[]` filter name match regex `^(Button|Badge|Input|StatusBadge|Toast|Modal)$`
2. Parse component file qua Grep regex `variant=\"([a-z][a-z_-]*)\"` (capture variant value)
3. Cross-ref `COMPONENT_VARIANTS.{Component}.variants[]`:
   - Variant value KHÔNG trong list → BUTTON_VARIANT_INCONSISTENT (severity SHOULD)
4. Skip components trong `exclusions.variant[]`

**Rule ID:** `UXDS-CD23-002`

**Signal payload:**
```json
{
  "kind": "BUTTON_VARIANT_INCONSISTENT",
  "severity": "SHOULD",
  "category": "VIOLATION",
  "rule_id": "UXDS-CD23-002",
  "message": "Button instance dùng variant='warning-soft' không tồn tại trong ux-conventions.component_variants.Button.variants",
  "affected_entities": ["Button"],
  "affected_files": ["apps/erp-web/components/order-actions.tsx"],
  "evidence": [{"file": "apps/erp-web/components/order-actions.tsx", "line": 24, "snippet": "<Button variant=\"warning-soft\">", "declared_variants": ["primary","secondary","ghost","destructive"]}],
  "suggested_action": "Đổi variant='destructive' hoặc add 'warning-soft' vào ux-conventions.json sau khi brand-guardian approve"
}
```

### Step CD23.4 — Color hardcoded (COLOR_HARDCODED)

> Special case của token drift — color drift nghiêm trọng nhất (brand-guardian gate).

**Logic:**
1. Iterate `fe-component-graph.nodes[]` ngoài `exclusions.color[]`
2. Grep color hex `#[0-9a-fA-F]{3,8}` strict (KHÔNG count tailwind `bg-red-500` class names)
3. Cross-ref `DESIGN_TOKENS.colors` palette:
   - Value KHÔNG trong palette → COLOR_HARDCODED (severity **MUST** — brand integrity)
4. Special detection: `style={{color: '#xxx'}}` inline style ALWAYS flag
5. Whitelist: comment `// @color-exception` hoặc components trong `components/ui/` shadcn base

**Rule ID:** `UXDS-CD23-003`

**Note:** Severity MUST vì color = brand identity. Brand-guardian veto right.

### Step CD23.5 — Typography drift (TYPOGRAPHY_DRIFT)

> Font-family / font-size / line-height không từ tokens.

**Logic:**
1. Iterate components, Grep:
   - `font-family:\s*['"]([^'"]+)['"]` (literal font family)
   - `font-size:\s*\d+(px|rem)` (literal size)
   - `line-height:\s*\d+(\.\d+)?(px|em|%)?` (literal line-height)
2. Cross-ref `DESIGN_TOKENS.typography`:
   - Font family KHÔNG trong `font_families[]` → TYPOGRAPHY_DRIFT (severity SHOULD)
   - Font size KHÔNG trong `font_sizes[]` scale → TYPOGRAPHY_DRIFT (severity SHOULD)
3. Skip components trong `exclusions.typography[]`

**Rule ID:** `UXDS-CD23-004`

### Step CD23.6 — Icon inconsistent (ICON_INCONSISTENT)

> Project dùng >1 icon library → bundle bloat + visual inconsistency.

**Logic:**
1. Quét `fe-component-graph.nodes[]` Grep imports pattern `from\s+['"](lucide-react|@heroicons|react-icons|@tabler/icons|@radix-ui/react-icons|phosphor-react|@material-ui/icons)['"]`
2. Build set unique icon libraries detected
3. Nếu count > 1 → ICON_INCONSISTENT (severity MAY — informational)
4. Cross-validate với `ux-conventions.icon_library` field (nếu khai báo) — non-matching lib → SHOULD

**Rule ID:** `UXDS-CD23-005`

**Note:** Severity MAY vì có thể intentional migration in-progress (vd legacy heroicons → lucide-react). Brand-guardian consult: chọn 1 chính thống.

### Step CD23.7 — Write signals.json (Atomic Write)

```bash
SIGNALS_TMP="$LANE_DIR/.signals.tmp.$$"

jq -n \
  --arg sid "$SESSION_ID" \
  --arg ts "$(date -Iseconds)" \
  --arg lane "CD23" \
  --arg agent "ui-designer" \
  --arg scope_type "$SCOPE_TYPE" \
  --argjson signals "$ALL_SIGNALS_JSON" \
  --argjson modules_covered "$MODULES_COVERED" \
  --arg ci "$CI_SOURCE" \
  '{
    "$schema": "signals-v1",
    "session_id": $sid,
    "generated_at": $ts,
    "lane": $lane,
    "agent_subagent_type": $agent,
    "scope": {"type": $scope_type, "modules": $modules_covered},
    "status": "COMPLETED",
    "scan_duration_sec": ($scan_duration | tonumber),
    "signals": $signals,
    "metadata": {
      "signal_count": ($signals | length),
      "severity_breakdown": {
        "MUST": ([$signals[] | select(.severity == "MUST")] | length),
        "SHOULD": ([$signals[] | select(.severity == "SHOULD")] | length),
        "MAY": ([$signals[] | select(.severity == "MAY")] | length),
        "INFO": ([$signals[] | select(.severity == "INFO")] | length)
      },
      "category_breakdown": {
        "MISSING_INVARIANT": ([$signals[] | select(.category == "MISSING_INVARIANT")] | length),
        "VIOLATION": ([$signals[] | select(.category == "VIOLATION")] | length),
        "GAP": ([$signals[] | select(.category == "GAP")] | length),
        "RECOMMENDATION": ([$signals[] | select(.category == "RECOMMENDATION")] | length)
      },
      "modules_covered": $modules_covered,
      "ci_source": $ci,
      "fallback_used": false
    }
  }' > "$SIGNALS_TMP"

jq '.' "$SIGNALS_TMP" >/dev/null || die "E044" "signals.json invalid JSON"
mv "$SIGNALS_TMP" "$LANE_DIR/signals.json"
```

| Tier | Check | Tool | Fail action |

| T1 | 3 output files exist | bash | **E044** — Output missing → auto-fix retry x3 |
| T2 | `signals.json` schema = `signals-v1`, `lane` = "CD23", fingerprint unique | jq | **E044** — Schema invalid → re-build |
| T3 | Mọi signal `rule_id` match format `UXDS-CD23-\d{3}` (001-005) AND tồn tại trong SSOT `validation_rules.rules[].id` cho rule_id 001/002 | jq | **E145** — Rule_id orphan → ESCALATE (signal false positive hoặc SSOT thiếu rule) |
| T4 | `affected_files[]` mọi signal resolve trong `fe-component-graph.json.nodes[].file_path` HOẶC mark là external (vd CSS variable file) | jq | **E045** — File unresolved → log WARN |

```bash
# T1
for f in signals.json CD23-ux-design-system-report.md lane-status.json; do
  [ -f "$LANE_DIR/$f" ] || die "E044" "Output missing: $f"
done

# T2
SCHEMA=$(jq -r '."$schema"' "$LANE_DIR/signals.json")
LANE_VAL=$(jq -r '.lane' "$LANE_DIR/signals.json")
[ "$SCHEMA" = "signals-v1" ] || die "E044" "Schema mismatch"
[ "$LANE_VAL" = "CD23" ] || die "E044" "Lane field mismatch"

FP_TOTAL=$(jq '.signals | length' "$LANE_DIR/signals.json")
FP_UNIQUE=$(jq '[.signals[].fingerprint] | unique | length' "$LANE_DIR/signals.json")
[ "$FP_TOTAL" = "$FP_UNIQUE" ] || die "E044" "Fingerprint collision"

# T3 — Rule ID format + SSOT mapping
INVALID_RULES=$(jq -r '[.signals[] | select(.rule_id | test("^UXDS-CD23-[0-9]{3}$") | not) | .rule_id] | length' "$LANE_DIR/signals.json")
[ "$INVALID_RULES" = "0" ] || die "E145" "Invalid rule_id format: $INVALID_RULES"

# T4 — File resolution (WARN only)
UNRESOLVED=$(jq -r --slurpfile g "$FE_COMP_GRAPH" \
  '[.signals[] | .affected_files[]?] | unique
   | map(select(. as $f | ($g[0].nodes | map(.file_path) | index($f)) == null))
   | length' "$LANE_DIR/signals.json")
[ "$UNRESOLVED" = "0" ] || log_warn "E045" "Unresolved files count: $UNRESOLVED (có thể CSS variable file ngoài graph)"
```
